流程控制简介

流程控制是编程中的核心概念，它决定了程序执行的顺序和条件。在C++中，流程控制语句允许我们根据不同的条件执行不同的代码块，或者重复执行某些代码。掌握流程控制是成为合格程序员的关键一步。

if条件语句

if语句是C++中最基本的条件控制语句，它根据条件的真假来决定是否执行特定的代码块。

基本语法

if (条件表达式) {
    // 如果条件为真，执行这里的代码
}

if-else语句

if (条件表达式) {
    // 如果条件为真，执行这里的代码
} else {
    // 如果条件为假，执行这里的代码
}

if-else if-else语句

if (条件1) {
    // 如果条件1为真，执行这里的代码
} else if (条件2) {
    // 如果条件2为真，执行这里的代码
} else {
    // 如果所有条件都为假，执行这里的代码
}

示例代码

#include <iostream>
using namespace std;

int main() {
    int score;
    cout << "请输入你的分数: ";
    cin >> score;
    
    if (score >= 90) {
        cout << "优秀！" << endl;
    } else if (score >= 80) {
        cout << "良好" << endl;
    } else if (score >= 60) {
        cout << "及格" << endl;
    } else {
        cout << "不及格，需要努力！" << endl;
    }
    
    return 0;
}
小贴士： 在if语句中，如果代码块只有一行，可以省略大括号，但为了代码清晰和避免错误，建议始终使用大括号。

switch多分支语句

switch语句用于基于不同的条件值执行不同的代码块，特别适合处理多个固定值的情况。

基本语法

switch (表达式) {
    case 值1:
        // 当表达式等于值1时执行
        break;
    case 值2:
        // 当表达式等于值2时执行
        break;
    default:
        // 当没有匹配的case时执行
}

switch语句的特点

特性 说明
表达式类型 只能是整型、字符型或枚举类型
case值 必须是常量表达式，不能是变量
break语句 用于跳出switch，防止case穿透
default 可选的，处理未匹配的情况

示例代码

#include <iostream>
using namespace std;

int main() {
    char grade;
    cout << "请输入你的等级(A/B/C/D/E): ";
    cin >> grade;
    
    switch (grade) {
        case 'A':
            cout << "优秀！" << endl;
            break;
        case 'B':
            cout << "良好" << endl;
            break;
        case 'C':
            cout << "中等" << endl;
            break;
        case 'D':
            cout << "及格" << endl;
            break;
        case 'E':
            cout << "不及格" << endl;
            break;
        default:
            cout << "无效的等级！" << endl;
    }
    
    return 0;
}
注意： 忘记写break语句会导致"case穿透"，即程序会继续执行下一个case的代码，直到遇到break或switch结束。

三元运算符

三元运算符是if-else语句的简洁形式，也称为条件运算符。

基本语法

条件 ? 表达式1 : 表达式2

如果条件为真，整个表达式的结果是表达式1的值；如果条件为假，结果是表达式2的值。

三元运算符 vs if-else

三元运算符

int max = (a > b) ? a : b;

优点：

  • 代码简洁
  • 可以直接用在表达式中
  • 适合简单的条件赋值

if-else语句

int max;
if (a > b) {
    max = a;
} else {
    max = b;
}

优点：

  • 可读性好
  • 可以执行多条语句
  • 适合复杂的条件逻辑

嵌套三元运算符

// 嵌套三元运算符示例
int result = (a > b) ? 
             ((a > c) ? a : c) : 
             ((b > c) ? b : c);
最佳实践： 三元运算符适合简单的条件判断，但嵌套过多会降低代码可读性，此时应使用if-else语句。

三种流程控制方式对比

特性 if语句 switch语句 三元运算符
适用场景 范围判断、复杂条件 固定值匹配 简单条件赋值
可读性 高 中 简单时高，复杂时低
灵活性 高 中 低
执行效率 取决于条件复杂度 通常较高（跳转表） 高

实战练习

现在让我们通过一个综合练习来巩固所学知识：

练习题目：成绩评级系统

编写一个程序，根据用户输入的成绩输出相应的等级：

  • 90-100: A
  • 80-89: B
  • 70-79: C
  • 60-69: D
  • 0-59: E

参考实现

#include <iostream>
using namespace std;

int main() {
    int score;
    char grade;
    
    cout << "请输入成绩(0-100): ";
    cin >> score;
    
    // 使用if-else语句确定等级
    if (score >= 90) {
        grade = 'A';
    } else if (score >= 80) {
        grade = 'B';
    } else if (score >= 70) {
        grade = 'C';
    } else if (score >= 60) {
        grade = 'D';
    } else {
        grade = 'E';
    }
    
    // 使用switch语句输出评价
    switch (grade) {
        case 'A':
            cout << "优秀！继续保持！" << endl;
            break;
        case 'B':
            cout << "良好，还有进步空间！" << endl;
            break;
        case 'C':
            cout << "中等，需要更加努力！" << endl;
            break;
        case 'D':
            cout << "及格，要加油了！" << endl;
            break;
        case 'E':
            cout << "不及格，需要加倍努力！" << endl;
            break;
    }
    
    // 使用三元运算符判断是否及格
    string result = (score >= 60) ? "恭喜你及格了！" : "很遗憾，不及格。";
    cout << result << endl;
    
    return 0;
}
挑战： 尝试修改程序，添加输入验证，确保用户输入的成绩在0-100范围内，如果不在范围内，要求重新输入。
