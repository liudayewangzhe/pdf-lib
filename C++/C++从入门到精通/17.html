C++运算符重载详解

成员函数重载、友元函数重载、常用运算符重载

什么是运算符重载？

运算符重载是C++中的一项强大功能，它允许我们重新定义大多数内置运算符的行为，使其能够用于自定义数据类型（如类或结构体）。通过运算符重载，我们可以使代码更直观、更易读。

运算符重载的优势：

  • 使自定义类型的使用更直观
  • 提高代码的可读性
  • 保持代码的一致性
  • 扩展语言功能

运算符重载的两种方式

1. 成员函数重载

运算符重载作为类的成员函数时，左侧操作数必须是该类的对象。

语法：

返回类型 operator运算符(参数列表) {
    // 函数体
}

示例：

class Complex {
private:
    double real, imag;
public:
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}
    
    // 成员函数重载 +
    Complex operator+(const Complex& other) const {
        return Complex(real + other.real, imag + other.imag);
    }
};

2. 友元函数重载

运算符重载作为友元函数时，可以访问类的私有成员，且操作数顺序更灵活。

语法：

friend 返回类型 operator运算符(参数列表) {
    // 函数体
}

示例：

class Complex {
private:
    double real, imag;
public:
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}
    
    // 友元函数重载 <<
    friend ostream& operator<<(ostream& os, const Complex& c) {
        os << c.real << " + " << c.imag << "i";
        return os;
    }
};

常用运算符重载示例

运算符 重载方式 示例代码 说明
算术运算符 (+, -, *, /) 成员函数/友元函数 Complex operator+(const Complex&) 实现自定义类型的算术运算
关系运算符 (==, !=, <, >) 成员函数/友元函数 bool operator==(const Complex&) 比较两个对象是否相等
赋值运算符 (=) 成员函数 Complex& operator=(const Complex&) 实现对象间的赋值
下标运算符 ([]) 成员函数 int& operator[](int index) 实现类似数组的访问
函数调用运算符 (()) 成员函数 返回值 operator()(参数) 创建函数对象（仿函数）
流运算符 (<<, >>) 友元函数 friend ostream& operator<<(ostream&, const T&) 实现自定义类型的输入输出

完整示例：复数类运算符重载

#include <iostream>
using namespace std;

class Complex {
private:
    double real, imag;
public:
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}
    
    // 成员函数重载 +
    Complex operator+(const Complex& other) const {
        return Complex(real + other.real, imag + other.imag);
    }
    
    // 成员函数重载 -
    Complex operator-(const Complex& other) const {
        return Complex(real - other.real, imag - other.imag);
    }
    
    // 成员函数重载 ==
    bool operator==(const Complex& other) const {
        return (real == other.real) && (imag == other.imag);
    }
    
    // 友元函数重载 <<
    friend ostream& operator<<(ostream& os, const Complex& c) {
        os << c.real;
        if (c.imag >= 0) os << " + " << c.imag << "i";
        else os << " - " << -c.imag << "i";
        return os;
    }
    
    // 友元函数重载 >>
    friend istream& operator>>(istream& is, Complex& c) {
        cout << "请输入实部: ";
        is >> c.real;
        cout << "请输入虚部: ";
        is >> c.imag;
        return is;
    }
};

int main() {
    Complex c1(3, 4), c2(1, 2);
    Complex c3 = c1 + c2;  // 使用重载的+运算符
    Complex c4 = c1 - c2;  // 使用重载的-运算符
    
    cout << "c1 = " << c1 << endl;
    cout << "c2 = " << c2 << endl;
    cout << "c1 + c2 = " << c3 << endl;
    cout << "c1 - c2 = " << c4 << endl;
    
    if (c1 == c2) {
        cout << "c1 等于 c2" << endl;
    } else {
        cout << "c1 不等于 c2" << endl;
    }
    
    return 0;
}

运算符重载的规则与限制

可以重载的运算符：

  • 算术运算符：+、-、*、/、%、++、--
  • 关系运算符：==、!=、<、>、<=、>=
  • 逻辑运算符：&&、||、!
  • 位运算符：&、|、~、^、<<、>>
  • 赋值运算符：=、+=、-=、*=、/=、%=、&=、|=、^=、<<=、>>=
  • 其他运算符：[]、()、->、,、new、delete、new[]、delete[]

不能重载的运算符：

  • 成员访问运算符：.（点运算符）
  • 成员指针访问运算符：.*
  • 作用域解析运算符：::
  • 条件运算符：?:
  • sizeof 运算符
  • typeid 运算符

运算符重载的重要规则：

  1. 不能创建新的运算符，只能重载已有的运算符
  2. 重载运算符时，至少有一个操作数是用户定义的类型
  3. 不能改变运算符的优先级和结合性
  4. 不能改变运算符的操作数个数
  5. 除函数调用运算符()外，其他重载运算符不能有默认参数

应该遵循的原则

  • 保持运算符的直观含义
  • 重载相关的一组运算符
  • 注意返回值类型的选择
  • 考虑异常安全性
  • 提供对称的运算符重载

应该避免的做法

  • 改变运算符的常规语义
  • 过度使用运算符重载
  • 重载不相关的运算符
  • 忽略性能影响
  • 违反运算符的数学规则

良好实践示例：

// 良好的运算符重载 - 保持直观含义
class Vector {
public:
    Vector operator+(const Vector& other) const;  // 向量加法
    Vector operator-(const Vector& other) const;  // 向量减法
    double operator*(const Vector& other) const;  // 点积
    bool operator==(const Vector& other) const;   // 相等比较
};
