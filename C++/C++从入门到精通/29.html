C++常量成员详解

const成员函数、const对象、mutable关键字

常量成员概述

在C++中，const关键字用于定义常量，它可以应用于变量、函数参数、函数返回值以及类的成员。当const与类的成员结合使用时，就形成了常量成员的概念，主要包括：

  • const成员函数 - 不能修改对象状态的成员函数
  • const对象 - 对象状态不能被修改的对象
  • mutable关键字 - 允许在const成员函数中修改的成员变量

const成员函数

const成员函数是在函数声明和定义后面加上const关键字的成员函数。这种函数承诺不会修改对象的任何非mutable成员变量。

语法格式

返回类型 函数名(参数列表) const {
    // 函数体
}

示例代码

class Student {
private:
    string name;
    int age;
    mutable int accessCount;  // 使用mutable修饰
    
public:
    Student(string n, int a) : name(n), age(a), accessCount(0) {}
    
    // const成员函数 - 不会修改对象状态
    string getName() const {
        accessCount++;  // 允许修改mutable成员
        return name;
    }
    
    int getAge() const {
        accessCount++;  // 允许修改mutable成员
        return age;
    }
    
    // 非const成员函数 - 可以修改对象状态
    void setAge(int newAge) {
        age = newAge;
    }
    
    int getAccessCount() const {
        return accessCount;
    }
};
提示： const成员函数可以被const对象和非const对象调用，但非const成员函数只能被非const对象调用。

const对象

const对象是在创建时使用const关键字修饰的对象。这种对象的状态在创建后不能被修改。

语法格式

const 类名 对象名(参数);

示例代码

// 创建const对象
const Student stu1("张三", 20);

// 以下代码会导致编译错误，因为const对象不能调用非const成员函数
// stu1.setAge(21);  // 错误！

// 但可以调用const成员函数
cout << "姓名：" << stu1.getName() << endl;
cout << "年龄：" << stu1.getAge() << endl;
注意： const对象只能调用const成员函数，不能调用非const成员函数，否则会导致编译错误。

mutable关键字

mutable关键字用于修饰类的成员变量，表示该变量即使在const成员函数中也可以被修改。

使用场景

  • 缓存计算结果
  • 访问计数
  • 调试信息记录
  • 线程同步相关的状态标志

示例代码

class Cache {
private:
    mutable string cachedValue;
    mutable bool isCached;
    string calculateValue() const;  // 复杂的计算函数
    
public:
    Cache() : isCached(false) {}
    
    string getValue() const {
        if (!isCached) {
            // 即使在const成员函数中，也可以修改mutable成员
            cachedValue = calculateValue();
            isCached = true;
        }
        return cachedValue;
    }
};

const成员函数 vs 非const成员函数

特性 const成员函数 非const成员函数
调用对象 const对象和非const对象 只能是非const对象
修改成员变量 只能修改mutable成员 可以修改所有非const成员
函数重载 可以与同名非const函数形成重载 可以与同名const函数形成重载
使用场景 获取对象状态，不改变对象 修改对象状态

综合示例

下面是一个完整的示例，展示了const成员函数、const对象和mutable关键字的综合应用：

#include <iostream>
#include <string>
using namespace std;

class BankAccount {
private:
    string accountHolder;
    double balance;
    mutable int transactionCount;  // 交易次数统计
    
public:
    BankAccount(string holder, double initialBalance) 
        : accountHolder(holder), balance(initialBalance), transactionCount(0) {}
    
    // const成员函数 - 获取账户信息
    string getHolder() const {
        return accountHolder;
    }
    
    double getBalance() const {
        return balance;
    }
    
    int getTransactionCount() const {
        return transactionCount;
    }
    
    // 非const成员函数 - 修改账户状态
    void deposit(double amount) {
        balance += amount;
        transactionCount++;
    }
    
    bool withdraw(double amount) {
        if (amount <= balance) {
            balance -= amount;
            transactionCount++;
            return true;
        }
        return false;
    }
    
    // const成员函数，但可以修改mutable成员
    void resetTransactionCount() const {
        transactionCount = 0;  // 允许修改mutable成员
    }
};

int main() {
    // 创建普通对象
    BankAccount account1("李四", 1000.0);
    
    // 创建const对象
    const BankAccount account2("王五", 500.0);
    
    // 普通对象可以调用所有函数
    account1.deposit(200.0);
    cout << "账户1余额：" << account1.getBalance() << endl;
    
    // const对象只能调用const成员函数
    cout << "账户2持有人：" << account2.getHolder() << endl;
    cout << "账户2余额：" << account2.getBalance() << endl;
    
    // 以下代码会导致编译错误
    // account2.deposit(100.0);  // 错误！const对象不能调用非const成员函数
    
    return 0;
}

最佳实践

设计原则

  • 将不修改对象状态的成员函数声明为const
  • 对于const对象，使用const成员函数来访问其状态
  • 谨慎使用mutable，只在确实需要的情况下使用
  • 考虑提供const和非const版本的重载函数

常见错误

  • 在const成员函数中修改非mutable成员
  • const对象调用非const成员函数
  • 过度使用mutable关键字，破坏了const的正确性
