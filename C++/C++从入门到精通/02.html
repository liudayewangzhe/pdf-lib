VS安装配置

安装步骤

  1. 访问Visual Studio官网下载Community版本（免费）
  2. 运行安装程序，选择"C++桌面开发"工作负载
  3. 勾选必要的组件：MSVC编译器、Windows SDK、CMake工具等
  4. 选择安装位置（建议保持默认）
  5. 等待下载和安装完成（可能需要30分钟到1小时）
  6. 首次启动时登录Microsoft账户（可选）

环境配置

配置项 推荐设置 说明
主题 深色/浅色 根据个人偏好选择，深色主题更适合长时间编码
字体 Cascadia Code / Consolas 等宽字体，便于代码对齐和阅读
缩进 4个空格 保持代码风格统一
编码 UTF-8 with BOM 确保中文支持良好

int WINAPI WinMain(HINSTANCE hInstance, 
                   HINSTANCE hPrevInstance, 
                   LPSTR lpCmdLine, 
                   int nCmdShow) {
    MessageBox(NULL, L"Hello Windows!", 
               L"我的应用", MB_OK);
    return 0;
}

调试技巧

基础调试功能

功能 快捷键 说明
设置断点 F9 在代码行左侧点击或按F9设置断点
开始调试 F5 启动调试，程序会在断点处暂停
逐语句 F11 单步执行，进入函数内部
逐过程 F10 单步执行，不进入函数内部
跳出 Shift+F11 执行完当前函数，返回到调用处

高级调试技巧

条件断点

只在特定条件下触发的断点

// 示例：当i等于5时触发断点
for (int i = 0; i < 10; i++) {
    // 设置条件断点：i == 5
    cout << i << endl;
}

数据断点

监视变量值变化时触发

int importantValue = 0;

// 当importantValue被修改时触发断点
importantValue = 42;  // 数据断点在这里触发

即时窗口

在调试时执行代码和表达式

// 在即时窗口中输入：
? variableName        // 查看变量值
? functionCall()      // 调用函数
? newValue = 42       // 修改变量值

插件安装方法

  1. 打开Visual Studio，点击"扩展"菜单
  2. 选择"管理扩展"
  3. 在左侧选择"联机"
  4. 搜索需要的插件名称
  5. 点击"下载"按钮
  6. 关闭所有VS窗口完成安装
  7. 重新启动Visual Studio
