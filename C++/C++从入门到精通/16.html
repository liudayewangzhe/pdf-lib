虚函数、纯虚函数、抽象类与动态绑定

多态简介 虚函数 纯虚函数 抽象类 动态绑定 综合示例

多态简介

多态是面向对象编程的三大特性之一（封装、继承、多态），它允许我们使用统一的接口来处理不同类型的对象。在C++中，多态主要通过虚函数实现。

多态的类型：

  • 编译时多态（静态绑定）： 通过函数重载和运算符重载实现
  • 运行时多态（动态绑定）： 通过虚函数和继承实现

虚函数

虚函数是在基类中使用 virtual 关键字声明的成员函数，它可以在派生类中被重新定义。当通过基类指针或引用调用虚函数时，会根据实际对象的类型调用相应的函数。

虚函数的特点

  • 使用 virtual 关键字声明
  • 在派生类中可以重写（override）
  • 通过基类指针或引用调用时，实现动态绑定
  • 虚函数可以有函数体
// 虚函数示例
class Animal {
public:
    virtual void speak() {
        cout << "动物发出声音" << endl;
    }
};

class Dog : public Animal {
public:
    void speak() override {
        cout << "汪汪！" << endl;
    }
};

class Cat : public Animal {
public:
    void speak() override {
        cout << "喵喵！" << endl;
    }
};

纯虚函数

纯虚函数是在基类中声明但没有定义的虚函数，通过在函数声明后添加 = 0 来标识。包含纯虚函数的类成为抽象类，不能实例化。

纯虚函数的特点

  • 使用 virtual 关键字和 = 0 声明
  • 没有函数体
  • 必须在派生类中被重写（除非派生类也是抽象类）
  • 使类成为抽象类
// 纯虚函数示例
class Shape {
public:
    // 纯虚函数
    virtual double area() const = 0;
    virtual double perimeter() const = 0;
    
    // 虚析构函数
    virtual ~Shape() {}
};

class Circle : public Shape {
private:
    double radius;
    
public:
    Circle(double r) : radius(r) {}
    
    double area() const override {
        return 3.14159 * radius * radius;
    }
    
    double perimeter() const override {
        return 2 * 3.14159 * radius;
    }
};

抽象类

抽象类是包含至少一个纯虚函数的类。抽象类不能被实例化，只能作为基类被继承。它的主要作用是为派生类提供统一的接口。

抽象类的特点

  • 包含至少一个纯虚函数
  • 不能创建对象实例
  • 可以包含数据成员和普通成员函数
  • 派生类必须重写所有纯虚函数才能实例化

抽象类示例

class Vehicle {
public:
    // 纯虚函数
    virtual void start() = 0;
    virtual void stop() = 0;
    
    // 普通成员函数
    void honk() {
        cout << "嘟嘟！" << endl;
    }
};

具体类示例

class Car : public Vehicle {
public:
    void start() override {
        cout << "汽车启动" << endl;
    }
    
    void stop() override {
        cout << "汽车停止" << endl;
    }
};

动态绑定

动态绑定（也称为后期绑定或运行时绑定）是指在程序运行时根据对象的实际类型来确定调用哪个函数。这是通过虚函数表（vtable）实现的。

动态绑定的工作原理

  1. 每个包含虚函数的类都有一个虚函数表（vtable）
  2. vtable中存储了指向类虚函数的指针
  3. 每个对象包含一个指向vtable的指针（vptr）
  4. 调用虚函数时，通过vptr找到vtable，然后调用相应的函数

动态绑定示例

// 动态绑定示例
Animal* animal1 = new Dog();
Animal* animal2 = new Cat();

animal1->speak();  // 输出: 汪汪！
animal2->speak();  // 输出: 喵喵！

// 释放内存
delete animal1;
delete animal2;

综合示例

下面是一个完整的示例，展示了多态在实际编程中的应用：

// 多态综合示例
#include <iostream>
#include <vector>
using namespace std;

// 抽象基类
class Employee {
protected:
    string name;
    double salary;
    
public:
    Employee(const string& n, double s) : name(n), salary(s) {}
    
    // 纯虚函数
    virtual double calculateBonus() const = 0;
    
    // 虚函数
    virtual void displayInfo() const {
        cout << "姓名: " << name << ", 基本工资: " << salary;
    }
    
    virtual ~Employee() {}
};

// 派生类 - 经理
class Manager : public Employee {
private:
    double bonusRate;
    
public:
    Manager(const string& n, double s, double br) 
        : Employee(n, s), bonusRate(br) {}
    
    double calculateBonus() const override {
        return salary * bonusRate;
    }
    
    void displayInfo() const override {
        Employee::displayInfo();
        cout << ", 职位: 经理, 奖金: " << calculateBonus() << endl;
    }
};

// 派生类 - 开发人员
class Developer : public Employee {
private:
    int overtimeHours;
    double overtimeRate;
    
public:
    Developer(const string& n, double s, int oh, double or) 
        : Employee(n, s), overtimeHours(oh), overtimeRate(or) {}
    
    double calculateBonus() const override {
        return overtimeHours * overtimeRate;
    }
    
    void displayInfo() const override {
        Employee::displayInfo();
        cout << ", 职位: 开发人员, 奖金: " << calculateBonus() << endl;
    }
};

int main() {
    vector<Employee*> employees;
    
    employees.push_back(new Manager("张三", 10000, 0.2));
    employees.push_back(new Developer("李四", 8000, 10, 100));
    employees.push_back(new Manager("王五", 12000, 0.25));
    employees.push_back(new Developer("赵六", 9000, 15, 100));
    
    // 使用多态处理不同类型的员工
    for (const auto& emp : employees) {
        emp->displayInfo();
    }
    
    // 释放内存
    for (auto emp : employees) {
        delete emp;
    }
    
    return 0;
}

示例输出：

姓名: 张三, 基本工资: 10000, 职位: 经理, 奖金: 2000
姓名: 李四, 基本工资: 8000, 职位: 开发人员, 奖金: 1000
姓名: 王五, 基本工资: 12000, 职位: 经理, 奖金: 3000
姓名: 赵六, 基本工资: 9000, 职位: 开发人员, 奖金: 1500

总结

概念 关键字 特点 用途
虚函数 virtual 可以重写，有函数体 实现运行时多态
纯虚函数 virtual ... = 0 必须重写，无函数体 定义接口规范
抽象类 包含纯虚函数 不能实例化 作为基类提供统一接口
动态绑定 通过虚函数实现 运行时确定函数调用 提高代码灵活性和可扩展性

多态的优势：

  • 代码复用： 通过继承复用基类代码
  • 接口统一： 使用基类指针处理不同派生类对象
  • 可扩展性： 添加新类不影响现有代码
  • 灵活性： 运行时决定调用哪个函数
