C++异常处理

try-catch块、异常类、自定义异常

什么是异常处理？

异常处理是C++中处理程序运行时错误的一种机制。当程序遇到无法正常处理的情况时（如除零、内存分配失败、文件不存在等），可以通过抛出异常来中断正常的程序流程，并由专门的异常处理代码来接管。

为什么要使用异常处理？

  • 将错误处理代码与正常业务逻辑分离
  • 提供统一的错误处理机制
  • 支持错误信息的传递
  • 提高代码的可读性和可维护性

try-catch块的基本语法

基本结构

try {
    // 可能抛出异常的代码
    // 如果发生异常，立即跳转到catch块
}
catch (异常类型1 参数1) {
    // 处理类型1的异常
}
catch (异常类型2 参数2) {
    // 处理类型2的异常
}
catch (...) {
    // 处理所有其他类型的异常
}

示例代码

#include <iostream>
#include <stdexcept>

int divide(int a, int b) {
    if (b == 0) {
        throw std::runtime_error("除数不能为零！");
    }
    return a / b;
}

int main() {
    try {
        int result = divide(10, 0);
        std::cout << "结果是: " << result << std::endl;
    }
    catch (const std::runtime_error& e) {
        std::cout << "捕获到异常: " << e.what() << std::endl;
    }
    catch (...) {
        std::cout << "捕获到未知异常" << std::endl;
    }
    
    return 0;
}

标准异常类

C++标准库提供了一系列异常类，它们都继承自std::exception基类。

异常类 头文件 描述
std::exception <exception> 所有标准异常类的基类
std::runtime_error <stdexcept> 运行时错误
std::logic_error <stdexcept> 逻辑错误
std::bad_alloc <new> 内存分配失败
std::out_of_range <stdexcept> 下标越界
std::invalid_argument <stdexcept> 无效参数

自定义异常类

我们可以创建自己的异常类来满足特定的需求，通常需要继承自标准异常类。

创建自定义异常类

#include <iostream>
#include <string>
#include <exception>

class MyException : public std::exception {
private:
    std::string message;
    
public:
    // 构造函数
    MyException(const std::string& msg) : message(msg) {}
    
    // 重写what()方法
    virtual const char* what() const noexcept override {
        return message.c_str();
    }
};

class FileNotFoundException : public std::runtime_error {
public:
    FileNotFoundException(const std::string& filename)
        : std::runtime_error("文件未找到: " + filename) {}
};

// 使用示例
void openFile(const std::string& filename) {
    // 模拟文件不存在的情况
    throw FileNotFoundException(filename);
}

int main() {
    try {
        openFile("data.txt");
    }
    catch (const FileNotFoundException& e) {
        std::cout << "文件操作错误: " << e.what() << std::endl;
    }
    catch (const std::exception& e) {
        std::cout << "标准异常: " << e.what() << std::endl;
    }
    
    return 0;
}

最佳实践：

  • 自定义异常类应该继承自std::exception或其派生类
  • 重写what()方法提供错误描述
  • 使用有意义的异常类名
  • 在异常消息中包含有用的调试信息

异常处理流程架构

异常处理的最佳实践

应该使用异常的情况：

  • 无法在本地处理的错误
  • 构造函数中的失败
  • 资源分配失败（内存、文件等）
  • 数学运算错误（除零、溢出等）
  • I/O操作失败

不应该使用异常的情况：

  • 正常的控制流程
  • 可预见的错误（使用返回值处理）
  • 性能关键的代码路径
  • 析构函数（谨慎使用）
实践原则 说明 示例
按特定性捕获 先捕获具体的异常，再捕获通用的异常 先FileNotFound，再exception
避免空的catch块 空的catch块会隐藏错误 至少记录错误信息
使用RAII 资源获取即初始化，确保资源释放 智能指针、文件流等
异常安全 确保异常不会导致资源泄漏或数据不一致 强异常安全保证

综合示例

#include <iostream>
#include <vector>
#include <stdexcept>
#include <memory>

// 自定义异常类
class VectorIndexException : public std::out_of_range {
public:
    VectorIndexException(int index, int size)
        : std::out_of_range("索引 " + std::to_string(index) + 
                           " 超出范围 [0, " + std::to_string(size-1) + "]") {}
};

class Calculator {
public:
    static double divide(double a, double b) {
        if (b == 0) {
            throw std::invalid_argument("除数不能为零");
        }
        return a / b;
    }
};

int main() {
    std::vector<int> numbers = {1, 2, 3, 4, 5};
    
    try {
        // 测试向量访问
        std::cout << "访问向量元素..." << std::endl;
        if (numbers.size() > 10) {  // 故意制造错误条件
            throw VectorIndexException(10, numbers.size());
        }
        
        // 测试除法运算
        std::cout << "进行除法运算..." << std::endl;
        double result = Calculator::divide(10, 0);
        std::cout << "结果: " << result << std::endl;
        
    }
    catch (const VectorIndexException& e) {
        std::cout << "向量索引错误: " << e.what() << std::endl;
    }
    catch (const std::invalid_argument& e) {
        std::cout << "数学运算错误: " << e.what() << std::endl;
    }
    catch (const std::exception& e) {
        std::cout << "标准异常: " << e.what() << std::endl;
    }
    catch (...) {
        std::cout << "未知异常发生" << std::endl;
    }
    
    std::cout << "程序继续执行..." << std::endl;
    return 0;
}
