C++ 结构体详解

什么是结构体？

结构体是C++中一种重要的复合数据类型，它允许我们将不同类型的数据组合在一起，形成一个整体。结构体就像是一个"数据容器"，可以把相关的数据打包在一起管理。

小贴士： 结构体非常适合用来表示现实世界中的对象，比如学生、图书、坐标点等。

结构体定义

定义结构体需要使用 struct 关键字，语法格式如下：

struct 结构体名称 {
    数据类型 成员变量1;
    数据类型 成员变量2;
    // ... 更多成员变量
};

结构体定义示例

// 定义学生结构体
struct Student {
    int id;          // 学号
    string name;     // 姓名
    int age;         // 年龄
    float score;     // 成绩
};

坐标点结构体

struct Point {
    int x;  // x坐标
    int y;  // y坐标
};

图书结构体

struct Book {
    string title;     // 书名
    string author;    // 作者
    float price;      // 价格
    int pages;        // 页数
};
注意： 结构体定义末尾的分号不能省略！

结构体变量声明和初始化

声明结构体变量

// 方法1：先定义结构体，再声明变量
struct Student {
    int id;
    string name;
    int age;
};

Student stu1;  // 声明一个Student类型的变量
// 方法2：定义结构体的同时声明变量
struct Student {
    int id;
    string name;
    int age;
} stu1, stu2;  // 同时声明两个变量

结构体初始化

// 方法1：逐个成员初始化
Student stu1;
stu1.id = 1001;
stu1.name = "张三";
stu1.age = 18;

// 方法2：声明时初始化
Student stu2 = {1002, "李四", 19};

// 方法3：C++11统一初始化
Student stu3{1003, "王五", 20};
初始化方式 语法示例 特点
逐个成员初始化 stu.id = 1001; 灵活，可以只初始化部分成员
声明时初始化 Student stu = {1001, "张三", 18}; 简洁，需要按顺序初始化所有成员
C++11统一初始化 Student stu{1001, "张三", 18}; 现代C++风格，推荐使用

结构体数组

结构体数组就是数组的每个元素都是一个结构体变量。这在处理多个相同类型的数据时非常有用。

结构体数组的定义和初始化

// 定义结构体数组
Student class1[5];  // 包含5个学生的数组

// 初始化结构体数组
Student students[3] = {
    {1001, "张三", 18, 85.5},
    {1002, "李四", 19, 92.0},
    {1003, "王五", 20, 78.5}
};

访问结构体数组成员

// 访问第一个学生的姓名
cout << students[0].name << endl;

// 修改第二个学生的成绩
students[1].score = 95.0;

// 遍历结构体数组
for(int i = 0; i < 3; i++) {
    cout << "学号: " << students[i].id 
         << ", 姓名: " << students[i].name 
         << ", 成绩: " << students[i].score << endl;
}

结构体指针

结构体指针就是指向结构体变量的指针。通过结构体指针可以访问和操作结构体的成员。

结构体指针的声明和使用

Student stu = {1001, "张三", 18, 85.5};
Student *pStu = &stu;  // 定义指向结构体的指针

// 通过指针访问结构体成员（使用->运算符）
cout << "学号: " << pStu->id << endl;
cout << "姓名: " << pStu->name << endl;

// 等价于使用(*指针).成员的方式
cout << "年龄: " << (*pStu).age << endl;

动态分配结构体内存

// 动态分配一个Student结构体
Student *pStu = new Student;

// 通过指针赋值
pStu->id = 1001;
pStu->name = "李四";
pStu->age = 19;
pStu->score = 90.5;

// 使用完毕后释放内存
delete pStu;
操作 普通变量 指针变量
访问成员 结构体变量.成员名 结构体指针->成员名
示例 stu.name pStu->name
等价形式 - (*pStu).name
记忆技巧： 点(.)操作符用于结构体变量，箭头(->)操作符用于结构体指针。

综合示例

下面是一个完整的使用结构体、结构体数组和结构体指针的示例程序：

#include <iostream>
#include <string>
using namespace std;

// 定义学生结构体
struct Student {
    int id;
    string name;
    int age;
    float score;
};

// 函数：打印学生信息
void printStudent(const Student &stu) {
    cout << "学号: " << stu.id 
         << ", 姓名: " << stu.name 
         << ", 年龄: " << stu.age 
         << ", 成绩: " << stu.score << endl;
}

// 函数：通过指针修改学生成绩
void updateScore(Student *pStu, float newScore) {
    pStu->score = newScore;
}

int main() {
    // 创建结构体数组
    Student class1[3] = {
        {1001, "张三", 18, 85.5},
        {1002, "李四", 19, 92.0},
        {1003, "王五", 20, 78.5}
    };
    
    // 使用指针遍历数组
    Student *p = class1;
    cout << "=== 学生信息 ===" << endl;
    for(int i = 0; i < 3; i++) {
        printStudent(*(p + i));
    }
    
    // 使用指针修改第二个学生的成绩
    updateScore(&class1[1], 95.5);
    
    cout << "\n=== 修改后的学生信息 ===" << endl;
    for(int i = 0; i < 3; i++) {
        printStudent(class1[i]);
    }
    
    // 动态创建结构体
    Student *newStu = new Student{1004, "赵六", 21, 88.0};
    cout << "\n=== 新学生信息 ===" << endl;
    printStudent(*newStu);
    
    delete newStu;  // 释放内存
    
    return 0;
}

结构体使用要点总结

  • 定义结构体：使用struct关键字，注意末尾分号
  • 访问成员：使用点(.)操作符访问结构体变量成员，使用箭头(->)操作符访问结构体指针成员
  • 结构体数组：适合存储多个相同类型的结构体数据
  • 结构体指针：可以指向结构体变量，用于动态内存分配和函数参数传递
  • 内存管理：动态分配的结构体需要使用delete释放内存
  • 初始化：可以使用多种方式初始化结构体，推荐使用C++11的统一初始化语法
最佳实践：
  • 给结构体起一个有意义的名称
  • 结构体成员变量命名要清晰明了
  • 对于大型结构体，使用指针传递避免拷贝开销
  • 使用const引用作为函数参数，防止意外修改
