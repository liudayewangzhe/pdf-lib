动态内存管理简介

在C++程序中，内存管理是一个至关重要的概念。动态内存分配允许程序在运行时请求和释放内存，这为处理可变大小的数据结构和优化内存使用提供了灵活性。

堆内存（动态内存）的特点是：

  • 生命周期由程序员控制
  • 分配和释放需要显式操作
  • 大小可以在运行时确定
  • 访问速度相对较慢

new和delete操作符

new和delete是C++中用于动态内存分配和释放的操作符。

基本用法

// 分配单个整型
int* ptr = new int;
*ptr = 42;
// 使用ptr...
delete ptr;

// 分配数组
int* arr = new int[10];
for (int i = 0; i < 10; i++) {
    arr[i] = i * i;
}
// 使用arr...
delete[] arr;

new和delete的配对使用

分配方式 释放方式 说明
new delete 单个对象
new[] delete[] 对象数组
new (nothrow) delete 不抛出异常的版本
注意：必须正确配对使用new/delete和new[]/delete[]，否则会导致未定义行为。

定位new表达式

#include <new>

char buffer[1024];  // 预分配的内存缓冲区

// 在指定内存位置构造对象
int* p = new (buffer) int(100);
// 注意：对于定位new，通常不需要调用delete

智能指针

智能指针是C++11引入的RAII（资源获取即初始化）技术的重要应用，用于自动管理动态内存。

unique_ptr

独占所有权的智能指针，不能拷贝，只能移动。

#include <memory>

// 创建unique_ptr
std::unique_ptr<int> ptr1 = std::make_unique<int>(42);
std::unique_ptr<int[]> arr = std::make_unique<int[]>(10);

// 转移所有权
std::unique_ptr<int> ptr2 = std::move(ptr1);

shared_ptr

共享所有权的智能指针，使用引用计数。

#include <memory>

// 创建shared_ptr
std::shared_ptr<int> ptr1 = std::make_shared<int>(42);
std::shared_ptr<int> ptr2 = ptr1;  // 共享所有权

// 获取引用计数
std::cout << "引用计数: " << ptr1.use_count() << std::endl;

weak_ptr

不控制对象生命周期的智能指针，用于解决shared_ptr的循环引用问题。

#include <memory>

std::shared_ptr<int> shared = std::make_shared<int>(100);
std::weak_ptr<int> weak = shared;

// 使用前需要转换为shared_ptr
if (auto temp = weak.lock()) {
    std::cout << "值: " << *temp << std::endl;
}

智能指针对比

类型 所有权 拷贝语义 适用场景
unique_ptr 独占 只能移动 单一所有者，性能要求高
shared_ptr 共享 可以拷贝 多个所有者，共享资源
weak_ptr 不拥有 可以拷贝 打破循环引用，观察者模式

内存泄漏检测

内存泄漏是指程序未能释放已经不再使用的内存，长期运行会导致内存耗尽。

常见的内存泄漏场景

  • 忘记调用delete
  • 异常导致delete未执行
  • 循环引用（使用shared_ptr时）
  • 容器中的指针未正确清理

检测工具和技术

Valgrind (Linux)

valgrind --leak-check=full ./your_program

Visual Studio诊断工具

// 在VS中启用内存诊断
#define _CRTDBG_MAP_ALLOC
#include <crtdbg.h>

// 在main函数结束前调用
_CrtDumpMemoryLeaks();

预防内存泄漏的最佳实践

  1. 优先使用智能指针而不是裸指针
  2. 遵循RAII原则
  3. 在构造函数中分配资源，在析构函数中释放
  4. 使用STL容器而不是手动管理数组
  5. 编写异常安全的代码

示例：使用RAII管理资源

class FileHandler {
private:
    FILE* file;
public:
    FileHandler(const char* filename, const char* mode) {
        file = fopen(filename, mode);
        if (!file) throw std::runtime_error("无法打开文件");
    }
    
    ~FileHandler() {
        if (file) fclose(file);
    }
    
    // 禁用拷贝
    FileHandler(const FileHandler&) = delete;
    FileHandler& operator=(const FileHandler&) = delete;
    
    // 允许移动
    FileHandler(FileHandler&& other) noexcept : file(other.file) {
        other.file = nullptr;
    }
    
    FileHandler& operator=(FileHandler&& other) noexcept {
        if (this != &other) {
            if (file) fclose(file);
            file = other.file;
            other.file = nullptr;
        }
        return *this;
    }
};

最佳实践总结

核心原则

  • 资源获取即初始化（RAII）：将资源生命周期与对象生命周期绑定
  • 优先使用栈对象：自动管理，无需手动释放
  • 智能指针优先：避免裸指针，减少内存泄漏风险
  • 明确所有权：清晰定义资源的拥有者和使用者
  • 异常安全：确保异常发生时资源能够正确释放

代码示例：现代C++内存管理

#include <memory>
#include <vector>
#include <string>

class ModernMemoryDemo {
private:
    std::unique_ptr<std::string> name;  // 独占资源
    std::shared_ptr<int> counter;       // 共享资源
    std::vector<std::unique_ptr<double>> data;  // 容器管理资源
    
public:
    ModernMemoryDemo(const std::string& n) 
        : name(std::make_unique<std::string>(n))
        , counter(std::make_shared<int>(0)) {
        
        // 安全地分配多个资源
        for (int i = 0; i < 10; ++i) {
            data.push_back(std::make_unique<double>(i * 3.14));
        }
    }
    
    // 自动生成的析构函数会正确释放所有资源
    // 不需要手动编写析构函数！
    
    // 示例方法
    void processData() {
        (*counter)++;
        for (const auto& item : data) {
            // 安全使用智能指针管理的资源
            std::cout << *item << " ";
        }
        std::cout << std::endl;
    }
};
