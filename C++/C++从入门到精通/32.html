C++ Lambda表达式

Lambda语法、捕获列表、Lambda应用详解

Lambda表达式简介

Lambda表达式是C++11引入的一项重要特性，它允许我们在需要函数对象的地方内联定义匿名函数。Lambda表达式使得代码更加简洁、易读，特别是在使用STL算法时。

提示： Lambda表达式本质上是一个匿名函数对象，编译器会将其转换为一个函数对象类。

Lambda表达式语法

Lambda表达式的基本语法如下：

[capture](parameters) mutable -> return-type { 
    // 函数体
}

语法组成部分

组成部分 描述 是否必需
捕获列表 [capture] 定义哪些外部变量可以在lambda体内访问 是
参数列表 (parameters) 与普通函数的参数列表类似 否（空时可省略）
mutable 修饰符 允许修改按值捕获的变量 否
返回类型 -> return-type 指定lambda的返回类型 否（可自动推导）
函数体 {} 包含lambda执行的代码 是

示例： 简单的Lambda表达式

// 定义一个简单的lambda，接受两个整数并返回它们的和
auto sum = [](int a, int b) -> int {
    return a + b;
};

// 使用lambda
int result = sum(5, 3); // result = 8

捕获列表详解

捕获列表定义了lambda表达式可以访问的外部变量。捕获方式分为值捕获和引用捕获。

捕获方式

捕获方式 语法 描述
不捕获任何变量 [] lambda不能访问任何外部变量
值捕获 [var] 按值捕获特定变量
引用捕获 [&var] 按引用捕获特定变量
隐式值捕获 [=] 按值捕获所有外部变量
隐式引用捕获 [&] 按引用捕获所有外部变量
混合捕获 [=, &var] 或 [&, var] 混合使用值和引用捕获

示例： 捕获列表的使用

int x = 10;
int y = 20;
int z = 30;

// 值捕获x，引用捕获y
auto lambda1 = [x, &y]() {
    // x是副本，可以读取但不能修改（除非使用mutable）
    // y是引用，可以读取和修改原变量
    y = x + y;
    return y;
};

// 隐式值捕获所有变量，但z使用引用捕获
auto lambda2 = [=, &z]() {
    z = x + y; // 修改的是外部变量z
    return x + y; // 使用的是x和y的副本
};

// 使用mutable允许修改值捕获的变量
auto lambda3 = [x]() mutable {
    x = x * 2; // 修改的是副本，不影响外部变量
    return x;
};

Lambda表达式应用

Lambda表达式在C++编程中有广泛的应用，特别是在STL算法、多线程编程和事件处理中。

1. 与STL算法结合使用

#include <algorithm>
#include <vector>
#include <iostream>

int main() {
    std::vector<int> numbers = {1, 5, 3, 8, 2, 7, 6, 4};
    
    // 使用lambda对vector进行排序
    std::sort(numbers.begin(), numbers.end(), [](int a, int b) {
        return a > b; // 降序排序
    });
    
    // 使用lambda查找满足条件的元素
    auto it = std::find_if(numbers.begin(), numbers.end(), [](int n) {
        return n % 2 == 0 && n > 4;
    });
    
    if (it != numbers.end()) {
        std::cout << "找到第一个大于4的偶数: " << *it << std::endl;
    }
    
    // 使用lambda转换元素
    std::vector<int> squares;
    std::transform(numbers.begin(), numbers.end(), std::back_inserter(squares),
                  [](int n) { return n * n; });
    
    return 0;
}

2. 在多线程编程中的应用

#include <thread>
#include <iostream>
#include <vector>

int main() {
    std::vector<std::thread> threads;
    int shared_data = 0;
    
    // 创建多个线程，使用lambda作为线程函数
    for (int i = 0; i < 5; ++i) {
        threads.emplace_back([i, &shared_data]() {
            // 每个线程增加shared_data
            for (int j = 0; j < 1000; ++j) {
                shared_data++;
            }
            std::cout << "线程 " << i << " 完成" << std::endl;
        });
    }
    
    // 等待所有线程完成
    for (auto& t : threads) {
        t.join();
    }
    
    std::cout << "最终结果: " << shared_data << std::endl;
    return 0;
}

3. 在GUI和事件处理中的应用

// 假设有一个按钮类，可以设置点击事件处理函数
class Button {
public:
    using ClickHandler = std::function<void()>;
    
    void setOnClick(ClickHandler handler) {
        clickHandler = handler;
    }
    
    void simulateClick() {
        if (clickHandler) {
            clickHandler();
        }
    }
    
private:
    ClickHandler clickHandler;
};

int main() {
    Button btn;
    int clickCount = 0;
    
    // 使用lambda设置按钮点击事件处理
    btn.setOnClick([&clickCount]() {
        clickCount++;
        std::cout << "按钮被点击了 " << clickCount << " 次" << std::endl;
    });
    
    // 模拟按钮点击
    btn.simulateClick();
    btn.simulateClick();
    btn.simulateClick();
    
    return 0;
}

最佳实践： 当lambda表达式较复杂或需要重复使用时，考虑使用命名函数或函数对象代替。对于简单的、一次性的操作，lambda表达式是最佳选择。
