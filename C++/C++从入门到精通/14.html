C++构造函数与析构函数

默认构造、拷贝构造、析构函数调用时机详解

📚 构造函数与析构函数概述

构造函数和析构函数是C++面向对象编程中的重要概念，它们负责对象的初始化和清理工作。

🏗️ 构造函数

在创建对象时自动调用，用于初始化对象的数据成员。

  • 与类同名
  • 无返回值类型
  • 可以重载

🧹 析构函数

在对象销毁时自动调用，用于释放对象占用的资源。

  • 类名前加~
  • 无参数
  • 不能重载

🔧 默认构造函数

默认构造函数是不带任何参数的构造函数，或者所有参数都有默认值的构造函数。

📝 定义方式

class MyClass {
public:
    // 默认构造函数
    MyClass() {
        // 初始化代码
    }
};

🎯 调用时机

场景 示例代码 说明
对象声明 MyClass obj; 创建栈对象
动态分配 MyClass *ptr = new MyClass(); 创建堆对象
数组创建 MyClass arr[5]; 创建对象数组

💡 示例代码

#include <iostream>
using namespace std;

class Student {
private:
    string name;
    int age;
public:
    // 默认构造函数
    Student() {
        name = "未知";
        age = 0;
        cout << "默认构造函数被调用" << endl;
    }
    
    void display() {
        cout << "姓名: " << name << ", 年龄: " << age << endl;
    }
};

int main() {
    Student s1;          // 调用默认构造函数
    Student *s2 = new Student(); // 调用默认构造函数
    s1.display();
    s2->display();
    delete s2;
    return 0;
}

📋 拷贝构造函数

拷贝构造函数用于用一个已存在的对象来初始化一个新对象。

📝 定义方式

class MyClass {
public:
    // 拷贝构造函数
    MyClass(const MyClass &obj) {
        // 拷贝逻辑
    }
};

🎯 调用时机

场景 示例代码 说明
对象初始化 MyClass obj2 = obj1; 用已有对象初始化新对象
函数参数传递 func(MyClass obj) 值传递对象参数
函数返回值 return obj; 返回对象值

💡 示例代码

#include <iostream>
using namespace std;

class Point {
private:
    int x, y;
public:
    Point(int xVal = 0, int yVal = 0) : x(xVal), y(yVal) {
        cout << "构造函数被调用" << endl;
    }
    
    // 拷贝构造函数
    Point(const Point &p) {
        x = p.x;
        y = p.y;
        cout << "拷贝构造函数被调用" << endl;
    }
    
    void display() {
        cout << "坐标: (" << x << ", " << y << ")" << endl;
    }
};

void showPoint(Point p) {  // 拷贝构造函数被调用
    p.display();
}

Point createPoint() {      // 返回时拷贝构造函数被调用
    Point temp(10, 20);
    return temp;
}

int main() {
    Point p1(5, 5);
    Point p2 = p1;        // 拷贝构造函数被调用
    showPoint(p1);        // 拷贝构造函数被调用
    Point p3 = createPoint(); // 拷贝构造函数被调用
    return 0;
}

⏰ 析构函数调用时机

析构函数在对象生命周期结束时自动调用，用于清理资源。

📝 定义方式

class MyClass {
public:
    // 析构函数
    ~MyClass() {
        // 清理代码
    }
};

🎯 调用时机

场景 触发条件 说明
栈对象 离开作用域 函数结束、代码块结束
堆对象 delete操作 显式释放内存
静态对象 程序结束 main函数结束
临时对象 表达式结束 生命周期结束

💡 示例代码

#include <iostream>
using namespace std;

class Resource {
private:
    string name;
public:
    Resource(string n) : name(n) {
        cout << "构造函数: " << name << endl;
    }
    
    ~Resource() {
        cout << "析构函数: " << name << endl;
    }
};

void testFunction() {
    Resource r1("局部对象");
    static Resource r2("静态对象");
    Resource *r3 = new Resource("堆对象");
    delete r3;  // 手动调用析构函数
}  // r1的析构函数被调用

int main() {
    cout << "进入main函数" << endl;
    testFunction();
    cout << "离开main函数" << endl;
    return 0;
}  // 静态对象r2的析构函数被调用

📊 构造函数与析构函数调用顺序

📝 重要规则

  • 构造顺序：基类 → 成员对象 → 派生类
  • 析构顺序：派生类 → 成员对象 → 基类（与构造相反）
  • 栈对象：后构造的先析构（LIFO原则）
  • 静态对象：在程序结束时析构

🎓 综合实例演示

#include <iostream>
#include <string>
using namespace std;

class Person {
private:
    string name;
    int age;
public:
    // 默认构造函数
    Person() : name("无名"), age(0) {
        cout << "Person默认构造函数: " << name << endl;
    }
    
    // 带参数构造函数
    Person(string n, int a) : name(n), age(a) {
        cout << "Person带参构造函数: " << name << endl;
    }
    
    // 拷贝构造函数
    Person(const Person &p) : name(p.name + "(副本)"), age(p.age) {
        cout << "Person拷贝构造函数: " << name << endl;
    }
    
    // 析构函数
    ~Person() {
        cout << "Person析构函数: " << name << endl;
    }
    
    void display() {
        cout << "姓名: " << name << ", 年龄: " << age << endl;
    }
};

void testPerson() {
    cout << "=== 进入testPerson函数 ===" << endl;
    
    Person p1;                          // 默认构造函数
    Person p2("张三", 20);              // 带参构造函数
    Person p3 = p2;                     // 拷贝构造函数
    
    p1.display();
    p2.display();
    p3.display();
    
    cout << "=== 离开testPerson函数 ===" << endl;
} // p3, p2, p1的析构函数依次被调用

int main() {
    cout << "=== 程序开始 ===" << endl;
    
    testPerson();
    
    Person *p4 = new Person("李四", 25); // 堆对象
    p4->display();
    delete p4;                          // 手动调用析构函数
    
    cout << "=== 程序结束 ===" << endl;
    return 0;
}

💡 最佳实践与注意事项

✅ 构造函数最佳实践

  • 使用初始化列表初始化成员变量
  • 为类提供合适的默认构造函数
  • 考虑使用explicit防止隐式转换
  • 在构造函数中避免调用虚函数

✅ 析构函数最佳实践

  • 为有动态内存分配的类定义析构函数
  • 将析构函数声明为virtual（基类）
  • 在析构函数中不要抛出异常
  • 遵循RAII原则

⚠️ 常见错误

  • 忘记释放动态分配的内存
  • 浅拷贝导致的问题
  • 构造函数中资源泄漏
  • 对象切片问题

🎯 关键要点总结

  1. 构造函数在对象创建时自动调用，用于初始化
  2. 拷贝构造函数在用已有对象创建新对象时调用
  3. 析构函数在对象销毁时自动调用，用于清理
  4. 构造和析构的顺序遵循特定规则
  5. 合理使用三法则（Rule of Three）
