C++ STL算法详解

排序算法、查找算法、数值算法

STL算法简介

STL（Standard Template Library）是C++标准库的重要组成部分，提供了丰富的通用算法。这些算法主要分为三类：排序算法、查找算法和数值算法。它们都定义在 <algorithm> 头文件中。

提示： 大多数STL算法都使用迭代器作为参数，这使得它们可以应用于各种容器。

排序算法

排序算法用于对容器中的元素进行排序。STL提供了多种排序算法，每种算法都有其特定的应用场景。

sort()

对指定范围内的元素进行排序，默认是升序排序。

#include <algorithm>
#include <vector>
#include <iostream>

int main() {
    std::vector<int> nums = {5, 2, 8, 1, 9};
    std::sort(nums.begin(), nums.end());
    
    for(int num : nums) {
        std::cout << num << " ";
    }
    // 输出: 1 2 5 8 9
    return 0;
}

stable_sort()

稳定排序，相等元素的相对顺序在排序后保持不变。

#include <algorithm>
#include <vector>

struct Student {
    std::string name;
    int score;
};

bool compareByScore(const Student& a, const Student& b) {
    return a.score < b.score;
}

int main() {
    std::vector<Student> students = {{"Alice", 85}, {"Bob", 85}, {"Charlie", 90}};
    std::stable_sort(students.begin(), students.end(), compareByScore);
    // Alice和Bob的相对顺序保持不变
    return 0;
}

partial_sort()

部分排序，只对指定范围内的前n个元素进行排序。

#include <algorithm>
#include <vector>
#include <iostream>

int main() {
    std::vector<int> nums = {9, 3, 6, 2, 7, 1, 8, 4, 5};
    // 只排序前5个最小的元素
    std::partial_sort(nums.begin(), nums.begin() + 5, nums.end());
    
    for(int num : nums) {
        std::cout << num << " ";
    }
    // 输出: 1 2 3 4 5 9 8 7 6
    return 0;
}

排序算法比较

算法 时间复杂度 稳定性 适用场景
sort() O(n log n) 不稳定 通用排序
stable_sort() O(n log n) 或 O(n (log n)^2) 稳定 需要保持相等元素顺序
partial_sort() O(n log k) 不稳定 只需要前k个有序元素

查找算法

查找算法用于在容器中搜索特定的元素或满足特定条件的元素。

find()

在指定范围内查找特定值。

#include <algorithm>
#include <vector>
#include <iostream>

int main() {
    std::vector<int> nums = {1, 2, 3, 4, 5};
    auto it = std::find(nums.begin(), nums.end(), 3);
    
    if(it != nums.end()) {
        std::cout << "找到元素: " << *it << std::endl;
    } else {
        std::cout << "未找到元素" << std::endl;
    }
    return 0;
}

binary_search()

在已排序的范围内进行二分查找。

#include <algorithm>
#include <vector>
#include <iostream>

int main() {
    std::vector<int> nums = {1, 2, 3, 4, 5, 6, 7, 8, 9};
    bool found = std::binary_search(nums.begin(), nums.end(), 5);
    
    if(found) {
        std::cout << "找到元素5" << std::endl;
    } else {
        std::cout << "未找到元素5" << std::endl;
    }
    return 0;
}

lower_bound() / upper_bound()

在已排序的范围内查找边界位置。

#include <algorithm>
#include <vector>
#include <iostream>

int main() {
    std::vector<int> nums = {1, 2, 2, 2, 3, 4, 5};
    
    // 查找第一个不小于2的位置
    auto lower = std::lower_bound(nums.begin(), nums.end(), 2);
    // 查找第一个大于2的位置
    auto upper = std::upper_bound(nums.begin(), nums.end(), 2);
    
    std::cout << "2的个数: " << std::distance(lower, upper) << std::endl;
    // 输出: 2的个数: 3
    return 0;
}
注意： 使用binary_search()、lower_bound()和upper_bound()前，必须确保容器已经排序，否则结果不可预测。

其他常用查找算法

  • find_if() - 查找满足特定条件的第一个元素
  • count() - 统计特定值出现的次数
  • count_if() - 统计满足特定条件的元素个数
  • search() - 在序列中查找子序列

数值算法

数值算法主要用于对序列进行数值计算，需要包含 <numeric> 头文件。

accumulate()

计算序列中所有元素的累加和。

#include <numeric>
#include <vector>
#include <iostream>

int main() {
    std::vector<int> nums = {1, 2, 3, 4, 5};
    int sum = std::accumulate(nums.begin(), nums.end(), 0);
    
    std::cout << "总和: " << sum << std::endl;
    // 输出: 总和: 15
    return 0;
}

inner_product()

计算两个序列的内积（点积）。

#include <numeric>
#include <vector>
#include <iostream>

int main() {
    std::vector<int> v1 = {1, 2, 3};
    std::vector<int> v2 = {4, 5, 6};
    
    int result = std::inner_product(v1.begin(), v1.end(), v2.begin(), 0);
    std::cout << "内积: " << result << std::endl;
    // 输出: 内积: 32 (1*4 + 2*5 + 3*6)
    return 0;
}

partial_sum()

计算序列的部分和。

#include <numeric>
#include <vector>
#include <iostream>
#include <iterator>

int main() {
    std::vector<int> nums = {1, 2, 3, 4, 5};
    std::vector<int> result(5);
    
    std::partial_sum(nums.begin(), nums.end(), result.begin());
    
    for(int num : result) {
        std::cout << num << " ";
    }
    // 输出: 1 3 6 10 15
    return 0;
}

其他数值算法

  • adjacent_difference() - 计算相邻元素的差值
  • iota() - 用连续递增的值填充序列

算法复杂度总结

stable_sort O(n log n) O(n (log n)^2)
partial_sort O(n log k) O(n log k)
查找算法 find O(n) O(n)
binary_search O(log n) O(log n)
lower_bound O(log n) O(log n)
count O(n) O(n)
数值算法 accumulate O(n) O(n)
inner_product O(n) O(n)

综合示例

下面是一个综合使用多种STL算法的示例：

#include <iostream>
#include <vector>
#include <algorithm>
#include <numeric>

int main() {
    // 创建并初始化向量
    std::vector<int> numbers = {7, 3, 5, 1, 9, 2, 8, 4, 6, 3, 5};
    
    std::cout << "原始数据: ";
    for(int num : numbers) {
        std::cout << num << " ";
    }
    std::cout << std::endl;
    
    // 排序
    std::sort(numbers.begin(), numbers.end());
    std::cout << "排序后: ";
    for(int num : numbers) {
        std::cout << num << " ";
    }
    std::cout << std::endl;
    
    // 查找
    auto it = std::find(numbers.begin(), numbers.end(), 5);
    if(it != numbers.end()) {
        std::cout << "找到数字5，位置: " << std::distance(numbers.begin(), it) << std::endl;
    }
    
    // 统计
    int count5 = std::count(numbers.begin(), numbers.end(), 5);
    std::cout << "数字5出现的次数: " << count5 << std::endl;
    
    // 数值计算
    int sum = std::accumulate(numbers.begin(), numbers.end(), 0);
    std::cout << "所有数字的和: " << sum << std::endl;
    
    // 去重
    auto last = std::unique(numbers.begin(), numbers.end());
    numbers.erase(last, numbers.end());
    std::cout << "去重后: ";
    for(int num : numbers) {
        std::cout << num << " ";
    }
    std::cout << std::endl;
    
    return 0;
}
编程技巧： 合理组合使用STL算法可以大大简化代码，提高开发效率。记住"不要重复造轮子"的原则，优先使用STL提供的算法。
