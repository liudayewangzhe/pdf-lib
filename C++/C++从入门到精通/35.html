多线程编程简介

多线程编程是现代软件开发中的重要技术，它允许程序同时执行多个任务，从而提高程序的执行效率和响应能力。在C++11之前，多线程编程依赖于平台特定的API（如Windows的CreateThread或POSIX的pthread_create）。C++11标准引入了<thread>头文件，为多线程编程提供了跨平台的支持。

多线程的优势

  • 提高性能：在多核处理器上并行执行任务，充分利用硬件资源
  • 提高响应性：在GUI应用程序中，后台任务不会阻塞用户界面
  • 简化建模：某些问题天然适合用多线程方式解决
  • 异步处理：可以同时处理多个I/O操作
注意：多线程编程也带来了复杂性，如竞态条件、死锁等问题，需要谨慎处理。

线程创建

在C++中，使用std::thread类来创建和管理线程。创建线程时，需要提供一个可调用对象（函数、函数对象、lambda表达式等）作为线程的入口点。

创建线程的几种方式

方式 示例 说明
函数指针 std::thread t(func); 使用普通函数作为线程入口
Lambda表达式 std::thread t([](){...}); 使用匿名函数作为线程入口
函数对象 std::thread t(Functor()); 使用重载了()运算符的类对象
成员函数 std::thread t(&Class::func, &obj); 使用类的成员函数作为线程入口

线程创建示例代码

#include <iostream>
#include <thread>
#include <vector>

// 简单的线程函数
void hello() {
    std::cout << "Hello from thread " << std::this_thread::get_id() << std::endl;
}

// 带参数的线程函数
void print_number(int num) {
    std::cout << "Number: " << num << std::endl;
}

// 函数对象
class Counter {
public:
    void operator()(int n) {
        for (int i = 0; i < n; ++i) {
            std::cout << "Count: " << i << std::endl;
        }
    }
};

int main() {
    // 方式1: 使用函数指针
    std::thread t1(hello);
    
    // 方式2: 使用带参数的函数
    std::thread t2(print_number, 42);
    
    // 方式3: 使用函数对象
    std::thread t3(Counter(), 5);
    
    // 方式4: 使用Lambda表达式
    std::thread t4([]() {
        std::cout << "Hello from lambda thread" << std::endl;
    });
    
    // 等待所有线程完成
    t1.join();
    t2.join();
    t3.join();
    t4.join();
    
    return 0;
}
提示：使用join()等待线程完成，或使用detach()分离线程使其在后台运行。分离的线程不能再被连接。

线程同步

当多个线程访问共享资源时，可能会发生数据竞争和不一致的问题。线程同步是确保多个线程正确、有序地访问共享资源的技术。

常见的线程同步问题

  • 竞态条件：多个线程同时访问共享数据，结果取决于执行顺序
  • 死锁：两个或多个线程互相等待对方释放资源
  • 活锁：线程不断改变状态以响应其他线程，但无法取得进展
  • 资源饥饿：线程长时间无法获取所需资源

C++中的同步机制

机制 头文件 用途
互斥锁 (Mutex) <mutex> 保护共享数据，防止同时访问
条件变量 (Condition Variable) <condition_variable> 线程间通信，等待特定条件
原子操作 (Atomic) <atomic> 无需锁的线程安全操作
锁保护 (Lock Guard) <mutex> RAII风格的锁管理
信号量 (Semaphore) <semaphore> (C++20) 控制对共享资源的访问数量

互斥锁 (Mutex)

互斥锁是最基本的同步机制，用于保护共享数据，确保同一时间只有一个线程可以访问受保护的资源。

C++中的互斥锁类型

类型 说明 适用场景
std::mutex 基本的互斥锁 一般用途
std::recursive_mutex 可重入互斥锁 同一线程多次加锁
std::timed_mutex 带超时的互斥锁 需要尝试加锁的场景
std::recursive_timed_mutex 可重入带超时的互斥锁 复杂加锁需求

互斥锁使用示例

#include <iostream>
#include <thread>
#include <mutex>
#include <vector>

std::mutex g_mutex;
int g_counter = 0;

void increment() {
    for (int i = 0; i < 100000; ++i) {
        // 使用锁保护共享资源
        std::lock_guard<std::mutex> lock(g_mutex);
        ++g_counter;
    }
}

void increment_with_try_lock() {
    for (int i = 0; i < 100000; ++i) {
        // 尝试加锁，如果失败则跳过
        if (g_mutex.try_lock()) {
            ++g_counter;
            g_mutex.unlock();
        }
    }
}

int main() {
    std::vector<std::thread> threads;
    
    // 创建10个线程
    for (int i = 0; i < 10; ++i) {
        threads.push_back(std::thread(increment));
    }
    
    // 等待所有线程完成
    for (auto& t : threads) {
        t.join();
    }
    
    std::cout << "Final counter value: " << g_counter << std::endl;
    
    return 0;
}

锁管理类

C++提供了几种锁管理类，用于自动管理锁的生命周期：

  • std::lock_guard：简单的RAII锁管理，构造时加锁，析构时解锁
  • std::unique_lock：更灵活的锁管理，可以延迟加锁、手动解锁
  • std::scoped_lock (C++17)：可以同时锁定多个互斥锁，避免死锁
避免死锁：当需要锁定多个互斥锁时，总是以相同的顺序加锁，或使用std::lock同时锁定多个互斥锁。

条件变量 (Condition Variable)

条件变量用于线程间的通信，允许线程等待某个条件成立。通常与互斥锁一起使用，用于实现生产者-消费者模式等同步场景。

条件变量的基本操作

  • wait()：等待条件成立，会释放互斥锁并阻塞线程
  • notify_one()：通知一个等待的线程
  • notify_all()：通知所有等待的线程

条件变量使用示例

#include <iostream>
#include <thread>
#include <mutex>
#include <condition_variable>
#include <queue>

std::mutex g_mutex;
std::condition_variable g_cv;
std::queue<int> g_data_queue;
bool g_done = false;

// 生产者线程函数
void producer() {
    for (int i = 0; i < 10; ++i) {
        std::this_thread::sleep_for(std::chrono::milliseconds(100));
        
        // 生产数据
        {
            std::lock_guard<std::mutex> lock(g_mutex);
            g_data_queue.push(i);
            std::cout << "Produced: " << i << std::endl;
        }
        
        // 通知消费者
        g_cv.notify_one();
    }
    
    // 生产完成
    {
        std::lock_guard<std::mutex> lock(g_mutex);
        g_done = true;
    }
    g_cv.notify_all();
}

// 消费者线程函数
void consumer() {
    while (true) {
        std::unique_lock<std::mutex> lock(g_mutex);
        
        // 等待条件：队列不为空或生产完成
        g_cv.wait(lock, []() {
            return !g_data_queue.empty() || g_done;
        });
        
        // 检查是否结束
        if (g_done && g_data_queue.empty()) {
            break;
        }
        
        // 消费数据
        int data = g_data_queue.front();
        g_data_queue.pop();
        lock.unlock();
        
        std::cout << "Consumed: " << data << std::endl;
    }
}

int main() {
    std::thread producer_thread(producer);
    std::thread consumer_thread(consumer);
    
    producer_thread.join();
    consumer_thread.join();
    
    std::cout << "Producer-consumer example completed." << std::endl;
    
    return 0;
}
提示：使用条件变量时，通常需要配合一个谓词（条件检查）来避免虚假唤醒。虚假唤醒是指线程在没有收到通知的情况下从等待状态返回。

综合示例：线程安全的队列

下面是一个使用互斥锁和条件变量实现的线程安全队列，这是一个在实际多线程编程中非常有用的工具类。

#include <queue>
#include <mutex>
#include <condition_variable>
#include <memory>

template<typename T>
class ThreadSafeQueue {
private:
    mutable std::mutex m_mutex;
    std::queue<T> m_queue;
    std::condition_variable m_cond;

public:
    ThreadSafeQueue() = default;
    ThreadSafeQueue(const ThreadSafeQueue& other) {
        std::lock_guard<std::mutex> lock(other.m_mutex);
        m_queue = other.m_queue;
    }
    
    // 禁止赋值操作
    ThreadSafeQueue& operator=(const ThreadSafeQueue&) = delete;
    
    // 向队列添加元素
    void push(T value) {
        std::lock_guard<std::mutex> lock(m_mutex);
        m_queue.push(std::move(value));
        m_cond.notify_one();
    }
    
    // 尝试从队列取出元素
    bool try_pop(T& value) {
        std::lock_guard<std::mutex> lock(m_mutex);
        if (m_queue.empty()) {
            return false;
        }
        value = std::move(m_queue.front());
        m_queue.pop();
        return true;
    }
    
    // 等待并取出元素
    void wait_and_pop(T& value) {
        std::unique_lock<std::mutex> lock(m_mutex);
        m_cond.wait(lock, [this]() { return !m_queue.empty(); });
        value = std::move(m_queue.front());
        m_queue.pop();
    }
    
    // 返回队列是否为空
    bool empty() const {
        std::lock_guard<std::mutex> lock(m_mutex);
        return m_queue.empty();
    }
    
    // 返回队列大小
    size_t size() const {
        std::lock_guard<std::mutex> lock(m_mutex);
        return m_queue.size();
    }
};

// 使用示例
int main() {
    ThreadSafeQueue<int> queue;
    
    // 生产者线程
    std::thread producer([&queue]() {
        for (int i = 0; i < 10; ++i) {
            queue.push(i);
            std::this_thread::sleep_for(std::chrono::milliseconds(100));
        }
    });
    
    // 消费者线程
    std::thread consumer([&queue]() {
        for (int i = 0; i < 10; ++i) {
            int value;
            queue.wait_and_pop(value);
            std::cout << "Consumed: " << value << std::endl;
        }
    });
    
    producer.join();
    consumer.join();
    
    return 0;
}

多线程编程最佳实践

  • 尽量减少共享数据：使用线程本地存储或消息传递减少共享状态
  • 使用RAII管理锁：避免手动加锁解锁，使用lock_guard等
  • 避免死锁：按固定顺序加锁，或使用std::lock同时加锁
  • 优先使用高级抽象：如std::async和std::future
  • 测试多线程代码：使用线程分析工具检测竞态条件和死锁
