循环结构简介

循环结构是编程中非常重要的控制结构，它允许我们重复执行一段代码多次，直到满足特定条件为止。在C++中，主要有三种循环结构：

  • while循环 - 先判断条件，再执行循环体
  • do-while循环 - 先执行循环体，再判断条件
  • for循环 - 适合已知循环次数的场景
💡 学习提示： 理解循环的关键是掌握循环条件和循环体的执行顺序，以及如何避免无限循环。

while 循环

while循环是最基本的循环类型，它在每次循环开始前检查条件表达式。如果条件为真，则执行循环体；否则退出循环。

语法格式

while (条件表达式) {
    // 循环体 - 要重复执行的代码
}

执行流程

  1. 计算条件表达式的值
  2. 如果条件为真（非零），执行循环体
  3. 重复步骤1和2，直到条件为假

示例1：数字累加

#include <iostream>
using namespace std;

int main() {
    int i = 1, sum = 0;
    
    // 计算1到10的和
    while (i <= 10) {
        sum += i;
        i++;
    }
    
    cout << "1到10的和是: " << sum << endl;
    return 0;
}

示例2：用户输入验证

#include <iostream>
using namespace std;

int main() {
    int number;
    
    cout << "请输入一个正数: ";
    cin >> number;
    
    // 验证输入是否为正数
    while (number <= 0) {
        cout << "输入错误！请重新输入一个正数: ";
        cin >> number;
    }
    
    cout << "你输入的正数是: " << number << endl;
    return 0;
}
⚠️ 注意事项： 在while循环中，一定要确保循环条件最终会变为假，否则会导致无限循环！

do-while 循环

do-while循环与while循环类似，但它的循环体至少会执行一次，因为条件判断在循环体执行之后进行。

语法格式

do {
    // 循环体 - 要重复执行的代码
} while (条件表达式);

执行流程

  1. 执行循环体
  2. 计算条件表达式的值
  3. 如果条件为真，返回步骤1；否则退出循环

示例1：菜单选择

#include <iostream>
using namespace std;

int main() {
    int choice;
    
    do {
        cout << "\\n=== 菜单 ===\\n";
        cout << "1. 开始游戏\\n";
        cout << "2. 设置\\n";
        cout << "3. 退出\\n";
        cout << "请选择: ";
        cin >> choice;
        
        switch (choice) {
            case 1: cout << "开始游戏!\\n"; break;
            case 2: cout << "打开设置!\\n"; break;
            case 3: cout << "再见!\\n"; break;
            default: cout << "无效选择!\\n";
        }
    } while (choice != 3);
    
    return 0;
}

示例2：密码验证

#include <iostream>
using namespace std;

int main() {
    const int CORRECT_PASSWORD = 123456;
    int password;
    int attempts = 0;
    
    do {
        cout << "请输入密码: ";
        cin >> password;
        attempts++;
        
        if (password != CORRECT_PASSWORD) {
            cout << "密码错误! 请重试。\\n";
        }
    } while (password != CORRECT_PASSWORD && attempts < 3);
    
    if (password == CORRECT_PASSWORD) {
        cout << "登录成功!\\n";
    } else {
        cout << "尝试次数过多，账户已锁定!\\n";
    }
    
    return 0;
}
💡 应用场景： do-while循环特别适合需要至少执行一次的场景，如菜单显示、用户输入验证等。

for 循环

for循环是最常用的循环结构，特别适合在已知循环次数的情况下使用。它将循环控制变量的初始化、条件判断和更新都集中在一行中。

语法格式

for (初始化表达式; 条件表达式; 更新表达式) {
    // 循环体 - 要重复执行的代码
}

执行流程

  1. 执行初始化表达式（只执行一次）
  2. 计算条件表达式，如果为假则退出循环
  3. 执行循环体
  4. 执行更新表达式
  5. 返回步骤2

示例1：打印乘法表

#include <iostream>
using namespace std;

int main() {
    int num = 5;
    
    cout << "=== " << num << "的乘法表 ===\\n";
    
    for (int i = 1; i <= 10; i++) {
        cout << num << " × " << i << " = " << num * i << endl;
    }
    
    return 0;
}

示例2：数组遍历

#include <iostream>
using namespace std;

int main() {
    int scores[] = {85, 92, 78, 96, 88};
    int sum = 0;
    
    // 计算数组元素的总和
    for (int i = 0; i < 5; i++) {
        sum += scores[i];
    }
    
    double average = static_cast<double>(sum) / 5;
    cout << "平均分: " << average << endl;
    
    return 0;
}

for循环的变体

变体类型 语法 说明
范围for循环 for (auto element : collection) C++11引入，用于遍历容器
无限循环 for (;;) 省略所有表达式，创建无限循环
多变量循环 for (int i=0, j=10; i<j; i++, j--) 使用多个控制变量

嵌套循环

嵌套循环是指在一个循环体内包含另一个循环。这种结构常用于处理二维数据，如矩阵、表格等。

基本概念

在嵌套循环中，外层循环每执行一次，内层循环会完整地执行所有迭代。

示例1：打印星号图案

#include <iostream>
using namespace std;

int main() {
    int rows = 5;
    
    // 外层循环控制行数
    for (int i = 1; i <= rows; i++) {
        // 内层循环控制每行的星号数量
        for (int j = 1; j <= i; j++) {
            cout << "* ";
        }
        cout << endl;
    }
    
    return 0;
}

输出：

* 
* * 
* * * 
* * * * 
* * * * *

示例2：九九乘法表

#include <iostream>
using namespace std;

int main() {
    // 外层循环控制被乘数
    for (int i = 1; i <= 9; i++) {
        // 内层循环控制乘数
        for (int j = 1; j <= i; j++) {
            cout << j << "×" << i << "=";
            // 格式化输出，保持对齐
            if (i * j < 10) {
                cout << " ";
            }
            cout << i * j << "  ";
        }
        cout << endl;
    }
    
    return 0;
}

嵌套循环的应用场景

  • 二维数组处理 - 遍历矩阵、表格数据
  • 图形打印 - 打印各种图案、图形
  • 组合问题 - 计算排列组合
  • 游戏开发 - 棋盘类游戏的逻辑处理
⚠️ 性能注意： 嵌套循环的时间复杂度通常是O(n²)，在处理大数据量时要注意性能问题。

循环结构比较

不同的循环结构有各自的特点和适用场景，选择合适的循环结构可以让代码更加清晰和高效。

循环类型 特点 适用场景 注意事项
while循环 先判断条件，再执行循环体 循环次数不确定的情况 注意避免无限循环
do-while循环 先执行循环体，再判断条件 至少需要执行一次的场景 循环体至少执行一次
for循环 循环控制集中在一行 循环次数已知的情况 适合数组遍历
嵌套循环 循环内包含循环 处理多维数据 注意时间复杂度

循环控制语句

在循环中，我们还可以使用控制语句来改变循环的正常执行流程：

  • break - 立即退出当前循环
  • continue - 跳过本次循环的剩余代码，直接开始下一次循环
  • return - 退出整个函数（包括循环）

break和continue示例

#include <iostream>
using namespace std;

int main() {
    // 查找第一个能被3和5同时整除的数
    for (int i = 1; i <= 100; i++) {
        // 跳过偶数
        if (i % 2 == 0) {
            continue;
        }
        
        // 找到符合条件的数
        if (i % 3 == 0 && i % 5 == 0) {
            cout << "找到: " << i << endl;
            break;  // 找到后立即退出循环
        }
    }
    
    return 0;
}
💡 最佳实践：
  • 根据具体需求选择合适的循环结构
  • 在循环开始前明确循环条件和退出条件
  • 避免在循环体内修改循环控制变量（除非必要）
  • 对于复杂的嵌套循环，适当添加注释说明
