C++智能指针详解

unique_ptr、shared_ptr、weak_ptr 使用指南

智能指针简介

在C++中，内存管理是一个非常重要且容易出错的部分。传统上，我们使用new和delete来手动管理内存，但这容易导致内存泄漏、悬空指针等问题。

智能指针是C++11引入的一种RAII（资源获取即初始化）技术，能够自动管理动态分配的内存，确保在适当的时候释放资源。

注意：使用智能指针需要包含<memory>头文件。

智能指针类型对比

unique_ptr

所有权：独占所有权

复制：不允许

移动：允许

适用场景：单一所有者资源

性能：接近原始指针

shared_ptr

所有权：共享所有权

复制：允许

移动：允许

适用场景：多个所有者资源

性能：引用计数开销

weak_ptr

所有权：无所有权

复制：允许

移动：允许

适用场景：打破循环引用

性能：控制块开销

1. unique_ptr - 独占所有权的智能指针

unique_ptr是一种独占所有权的智能指针，它确保同一时间只有一个unique_ptr指向给定的对象。当unique_ptr被销毁时，它所指向的对象也会被自动删除。

基本用法

#include <memory>
#include <iostream>

// 创建一个unique_ptr
std::unique_ptr<int> ptr1 = std::make_unique<int>(42);

// 访问指针内容
std::cout << *ptr1 << std::endl; // 输出: 42

// 获取原始指针
int* raw_ptr = ptr1.get();

// 释放所有权
int* released_ptr = ptr1.release();
// 注意：release()后需要手动管理内存

转移所有权

// unique_ptr不能复制，但可以移动
std::unique_ptr<int> ptr2 = std::move(ptr1);

// 此时ptr1为空，ptr2拥有资源
if (!ptr1) {
    std::cout << "ptr1 is now empty" << std::endl;
}

自定义删除器

// 使用自定义删除器
auto deleter = [](int* p) {
    std::cout << "Deleting int: " << *p << std::endl;
    delete p;
};

std::unique_ptr<int, decltype(deleter)> ptr3(new int(100), deleter);

最佳实践：优先使用std::make_unique来创建unique_ptr，它更安全、更高效。

2. shared_ptr - 共享所有权的智能指针

shared_ptr通过引用计数实现共享所有权。当最后一个shared_ptr被销毁时，它所指向的对象才会被删除。

基本用法

#include <memory>
#include <iostream>

// 创建shared_ptr
std::shared_ptr<int> ptr1 = std::make_shared<int>(100);
std::shared_ptr<int> ptr2 = ptr1; // 共享所有权

std::cout << "ptr1 use_count: " << ptr1.use_count() << std::endl; // 输出: 2
std::cout << "ptr2 use_count: " << ptr2.use_count() << std::endl; // 输出: 2

引用计数机制

自定义删除器

// shared_ptr也可以使用自定义删除器
std::shared_ptr<int> ptr3(new int[10], [](int* p) {
    std::cout << "Deleting array" << std::endl;
    delete[] p;
});

注意：避免循环引用！如果两个shared_ptr相互引用，会导致内存泄漏。这种情况下应该使用weak_ptr。

3. weak_ptr - 弱引用智能指针

weak_ptr是一种不控制对象生命周期的智能指针，它指向一个由shared_ptr管理的对象，但不会增加引用计数。

基本用法

#include <memory>
#include <iostream>

std::shared_ptr<int> shared = std::make_shared<int>(200);
std::weak_ptr<int> weak = shared;

// 使用weak_ptr前需要转换为shared_ptr
if (auto temp = weak.lock()) {
    std::cout << "Value: " << *temp << std::endl;
} else {
    std::cout << "Object has been destroyed" << std::endl;
}

解决循环引用问题

class B; // 前向声明

class A {
public:
    std::shared_ptr<B> b_ptr;
    ~A() { std::cout << "A destroyed" << std::endl; }
};

class B {
public:
    std::weak_ptr<A> a_ptr; // 使用weak_ptr打破循环引用
    ~B() { std::cout << "B destroyed" << std::endl; }
};

// 使用示例
auto a = std::make_shared<A>();
auto b = std::make_shared<B>();
a->b_ptr = b;
b->a_ptr = a; // 使用weak_ptr，不会增加引用计数

智能指针使用场景总结

场景 推荐使用的智能指针 理由
单一函数内的资源管理 unique_ptr 性能最佳，语义明确
容器存储动态对象 unique_ptr 或 shared_ptr 自动内存管理，避免泄漏
多个对象共享资源 shared_ptr 引用计数自动管理生命周期
缓存或观察者模式 weak_ptr 不增加引用计数，避免循环引用
多态对象管理 shared_ptr 或 unique_ptr 支持多态删除，自动调用正确析构函数

综合示例

#include <memory>
#include <iostream>
#include <vector>

class Resource {
public:
    Resource(int id) : id(id) {
        std::cout << "Resource " << id << " created" << std::endl;
    }
    
    ~Resource() {
        std::cout << "Resource " << id << " destroyed" << std::endl;
    }
    
    void use() {
        std::cout << "Using resource " << id << std::endl;
    }
    
private:
    int id;
};

int main() {
    // 使用unique_ptr管理独占资源
    std::unique_ptr<Resource> unique = std::make_unique<Resource>(1);
    unique->use();
    
    // 使用shared_ptr管理共享资源
    std::shared_ptr<Resource> shared1 = std::make_shared<Resource>(2);
    std::shared_ptr<Resource> shared2 = shared1;
    
    std::cout << "Shared count: " << shared1.use_count() << std::endl;
    
    // 使用weak_ptr观察共享资源
    std::weak_ptr<Resource> weak = shared1;
    
    if (auto temp = weak.lock()) {
        temp->use();
    }
    
    // 在容器中使用智能指针
    std::vector<std::shared_ptr<Resource>> resources;
    resources.push_back(std::make_shared<Resource>(3));
    resources.push_back(std::make_shared<Resource>(4));
    
    for (const auto& res : resources) {
        res->use();
    }
    
    return 0;
}

常见问题与注意事项

不要混合使用原始指针和智能指针

// 错误示例
int* raw_ptr = new int(5);
std::shared_ptr<int> sp1(raw_ptr);
std::shared_ptr<int> sp2(raw_ptr); // 未定义行为！

优先使用make_shared和make_unique

// 推荐做法
auto sp = std::make_shared<MyClass>(arg1, arg2);
auto up = std::make_unique<MyClass>(arg1, arg2);

注意this指针问题

class MyClass : public std::enable_shared_from_this<MyClass> {
public:
    std::shared_ptr<MyClass> get_shared() {
        return shared_from_this();
    }
};
