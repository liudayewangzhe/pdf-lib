第13章：类和对象

类和对象简介

在C++中，类是面向对象编程的核心概念，它是一种用户自定义的数据类型，用于封装数据和对数据的操作。对象是类的实例，通过对象我们可以访问类中定义的成员变量和成员函数。

关键点： 类就像建筑物的蓝图，而对象则是根据这个蓝图建造的实际建筑物。

类定义

在C++中，我们使用class关键字来定义一个类。类定义包括数据成员（属性）和成员函数（方法）。

类定义的基本语法

class 类名 {
访问修饰符:
    // 数据成员（属性）
    数据类型 成员变量1;
    数据类型 成员变量2;
    ...
    
    // 成员函数（方法）
    返回类型 函数名1(参数列表);
    返回类型 函数名2(参数列表);
    ...
};

示例：定义一个学生类

class Student {
private:
    string name;
    int age;
    double score;
    
public:
    // 成员函数声明
    void setName(string n);
    void setAge(int a);
    void setScore(double s);
    void displayInfo();
};

对象创建

定义了类之后，我们可以创建该类的对象。对象是类的实例，每个对象都有自己的数据成员副本。

创建对象的方法

  • 栈上创建： 类名 对象名;
  • 堆上创建： 类名 *对象指针 = new 类名();

示例：创建学生对象

// 在栈上创建对象
Student stu1;
Student stu2;

// 在堆上创建对象
Student *pStu = new Student();

// 使用对象
stu1.setName("张三");
stu1.setAge(18);
stu1.setScore(95.5);
stu1.displayInfo();

// 使用指针访问对象
pStu->setName("李四");
pStu->setAge(19);
pStu->setScore(88.5);
pStu->displayInfo();

// 释放堆内存
delete pStu;

成员函数

成员函数是定义在类内部的函数，用于操作类的数据成员。成员函数可以在类内部定义，也可以在类外部定义。

成员函数的定义方式

定义方式 语法 特点
类内定义 在类声明内部直接定义函数 自动成为内联函数，适合简单函数
类外定义 在类声明外部使用作用域解析运算符::定义 适合复杂函数，使类声明更清晰

示例：成员函数的定义

class Student {
private:
    string name;
    int age;
    double score;
    
public:
    // 类内定义的成员函数（自动内联）
    void setName(string n) {
        name = n;
    }
    
    void setAge(int a) {
        age = a;
    }
    
    // 类外定义的成员函数声明
    void setScore(double s);
    void displayInfo();
};

// 类外定义的成员函数
void Student::setScore(double s) {
    score = s;
}

void Student::displayInfo() {
    cout << "姓名：" << name << endl;
    cout << "年龄：" << age << endl;
    cout << "成绩：" << score << endl;
}

访问控制

C++提供了三种访问修饰符来控制类成员的访问权限：public、private和protected。

public（公有）

公有成员在类的外部可以直接访问，通常用于定义类的接口。

  • 任何地方都可以访问
  • 通常用于成员函数
  • 提供类的公共接口

private（私有）

私有成员只能在类的内部访问，通常用于封装数据。

  • 只能在类内部访问
  • 通常用于数据成员
  • 实现数据隐藏

protected（保护）

保护成员在类的内部和派生类中可以访问，但在类的外部不能访问。

  • 类内部和派生类中可访问
  • 类外部不可访问
  • 用于继承关系

示例：访问控制的实际应用

class BankAccount {
private:
    string accountNumber;  // 私有：外部不能直接访问
    double balance;        // 私有：外部不能直接访问
    
public:
    // 公有：外部可以访问的接口
    void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }
    
    bool withdraw(double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount;
            return true;
        }
        return false;
    }
    
    double getBalance() {
        return balance;  // 通过公有函数访问私有数据
    }
};

// 使用示例
BankAccount account;
account.deposit(1000);      // 正确：公有函数可以调用
// account.balance = 5000;  // 错误：私有成员不能直接访问
double currentBalance = account.getBalance();  // 正确：通过公有接口访问

综合示例

下面是一个完整的学生类示例，展示了类定义、对象创建、成员函数和访问控制的综合应用。

#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    int age;
    double score;
    
public:
    // 设置学生信息
    void setInfo(string n, int a, double s) {
        name = n;
        age = a;
        score = s;
    }
    
    // 获取学生姓名
    string getName() {
        return name;
    }
    
    // 获取学生年龄
    int getAge() {
        return age;
    }
    
    // 获取学生成绩
    double getScore() {
        return score;
    }
    
    // 显示学生信息
    void displayInfo() {
        cout << "=== 学生信息 ===" << endl;
        cout << "姓名: " << name << endl;
        cout << "年龄: " << age << endl;
        cout << "成绩: " << score << endl;
        cout << "===============" << endl;
    }
    
    // 判断是否优秀（成绩 >= 90）
    bool isExcellent() {
        return score >= 90;
    }
};

int main() {
    // 创建学生对象
    Student stu1, stu2;
    
    // 设置学生信息
    stu1.setInfo("张三", 18, 95.5);
    stu2.setInfo("李四", 19, 85.0);
    
    // 显示学生信息
    stu1.displayInfo();
    stu2.displayInfo();
    
    // 判断是否优秀
    if (stu1.isExcellent()) {
        cout << stu1.getName() << "是优秀学生！" << endl;
    }
    
    if (stu2.isExcellent()) {
        cout << stu2.getName() << "是优秀学生！" << endl;
    } else {
        cout << stu2.getName() << "需要继续努力！" << endl;
    }
    
    return 0;
}

本章总结

类定义

  • 使用class关键字定义类
  • 包含数据成员和成员函数
  • 是对象的蓝图

对象创建

  • 对象是类的实例
  • 可以在栈或堆上创建
  • 每个对象有独立的数据

成员函数

  • 操作类的数据成员
  • 可以在类内或类外定义
  • 使用作用域解析运算符::

访问控制

  • public：类内外均可访问
  • private：仅类内访问
  • protected：类内和派生类访问

学习建议

1. 理解类和对象的关系：类就像蓝图，对象是具体的实例

2. 掌握访问控制的重要性：合理使用public、private实现封装

3. 多练习：通过实际编程加深对面向对象概念的理解

4. 思考设计：考虑哪些成员应该是public，哪些应该是private
