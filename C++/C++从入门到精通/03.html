C++基础语法

注释、变量与常量、基本数据类型、关键字与标识符

一、注释

注释是程序中用于解释代码的文字，编译器会忽略注释内容。C++中有两种注释方式：

1. 单行注释

使用双斜杠//，从//开始到行尾的内容都是注释。

// 这是一个单行注释
int age = 18; // 声明一个整数变量age并赋值为18

2. 多行注释

使用/*和*/包围注释内容，可以跨越多行。

/*
这是一个多行注释
可以跨越多行
常用于函数说明或复杂逻辑解释
*/
int calculate(int a, int b) {
    return a + b;
}
注意： 注释不能嵌套使用，良好的注释习惯是优秀程序员的标志。

二、变量与常量

1. 变量

变量是程序中用于存储数据的内存空间，其值可以在程序运行过程中改变。

变量声明语法：

数据类型 变量名;

变量初始化：

数据类型 变量名 = 初始值;

示例：

int age;           // 声明一个整数变量
age = 18;         // 给变量赋值
int score = 95;   // 声明并初始化变量
double price = 19.99;  // 声明双精度浮点数变量
char grade = 'A';      // 声明字符变量

2. 常量

常量是其值在程序运行过程中不能改变的量。

定义常量的两种方式：

  • #define 预处理器
  • const 关键字

示例：

#define PI 3.14159          // 使用#define定义常量
const int MAX_SIZE = 100;  // 使用const定义常量

三、基本数据类型

C++提供了多种基本数据类型来存储不同种类的数据。

数据类型 描述 大小 取值范围 示例
int 整型 4字节 -2,147,483,648 到 2,147,483,647 int age = 18;
float 单精度浮点型 4字节 ±3.4e±38（约7位有效数字） float price = 19.99f;
double 双精度浮点型 8字节 ±1.7e±308（约15位有效数字） double pi = 3.14159;
char 字符型 1字节 -128 到 127 或 0 到 255 char grade = 'A';
bool 布尔型 1字节 true 或 false bool isPass = true;
void 无类型 N/A N/A 用于函数无返回值

数据类型使用示例：

#include <iostream>
using namespace std;

int main() {
    // 整型
    int age = 18;
    
    // 浮点型
    float height = 1.75f;
    double weight = 65.5;
    
    // 字符型
    char grade = 'A';
    
    // 布尔型
    bool isStudent = true;
    
    // 输出变量值
    cout << "年龄: " << age << endl;
    cout << "身高: " << height << "米" << endl;
    cout << "体重: " << weight << "公斤" << endl;
    cout << "成绩: " << grade << endl;
    cout << "是学生: " << isStudent << endl;
    
    return 0;
}

四、关键字与标识符

1. 关键字

关键字是C++语言中预先定义的、具有特殊含义的单词，不能用作标识符。

常见C++关键字：

int float double char bool void if else for while do switch case break continue return class struct public private protected new delete const static

2. 标识符

标识符是程序员为变量、函数、类等起的名字。

标识符命名规则：

  • 只能包含字母、数字和下划线（_）
  • 必须以字母或下划线开头
  • 不能是C++关键字
  • 区分大小写

标识符命名规范（良好编程习惯）：

  • 使用有意义的名称
  • 变量名使用小写字母，单词间用下划线分隔
  • 常量名使用大写字母，单词间用下划线分隔
  • 函数名使用小写字母，单词间用下划线分隔或驼峰命名法

标识符示例：

// 合法的标识符
int age;
float average_score;
double pi_value;
char first_name;
bool is_valid;

// 不合法的标识符
int 2age;        // 不能以数字开头
float average-score; // 不能包含连字符
double class;    // 不能使用关键字

五、综合示例

下面是一个综合示例，演示了注释、变量、常量、数据类型和标识符的使用：

#include <iostream>
using namespace std;

// 使用const定义常量
const double PI = 3.14159;
const int MAX_STUDENTS = 50;

int main() {
    // 变量声明和初始化
    int student_count = 30;
    float average_score = 85.5f;
    char class_grade = 'B';
    bool is_full = false;
    
    // 输出信息
    cout << "班级信息：" << endl;
    cout << "学生人数: " << student_count << endl;
    cout << "平均分: " << average_score << endl;
    cout << "班级等级: " << class_grade << endl;
    cout << "是否满员: " << (is_full ? "是" : "否") << endl;
    
    // 计算圆的面积
    double radius = 5.0;
    double area = PI * radius * radius;
    cout << "半径为" << radius << "的圆面积: " << area << endl;
    
    return 0;
}
