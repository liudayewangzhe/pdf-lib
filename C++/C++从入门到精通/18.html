C++模板：函数模板、类模板、模板特化

掌握C++模板编程，编写通用、高效的代码

什么是模板？

模板是C++中的一种强大特性，它允许我们编写与类型无关的通用代码。通过模板，我们可以实现代码的复用，提高开发效率。

注意：模板是C++泛型编程的基础，它使得代码更加灵活和可重用。

函数模板

函数模板允许我们定义一个通用的函数，可以处理多种数据类型。

函数模板语法

template <typename T>
返回类型 函数名(参数列表) {
    // 函数体
}

函数模板示例

#include <iostream>
using namespace std;

// 定义一个交换两个值的函数模板
template <typename T>
void swapValues(T &a, T &b) {
    T temp = a;
    a = b;
    b = temp;
}

// 定义一个返回较大值的函数模板
template <typename T>
T getMax(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    int x = 5, y = 10;
    cout << "交换前: x = " << x << ", y = " << y << endl;
    swapValues(x, y);
    cout << "交换后: x = " << x << ", y = " << y << endl;
    
    double d1 = 3.14, d2 = 2.71;
    cout << "较大的双精度数: " << getMax(d1, d2) << endl;
    
    char c1 = 'A', c2 = 'Z';
    cout << "较大的字符: " << getMax(c1, c2) << endl;
    
    return 0;
}

函数模板的优点

  • 代码复用：同一套代码可以用于多种数据类型
  • 类型安全：编译时进行类型检查
  • 性能优秀：编译时生成特定类型的代码，无运行时开销

类模板

类模板允许我们定义通用的类，可以处理多种数据类型。

类模板语法

template <typename T1, typename T2, ...>
class 类名 {
    // 类成员
};

类模板示例

#include <iostream>
#include <vector>
using namespace std;

// 定义一个简单的栈类模板
template <typename T>
class Stack {
private:
    vector<T> elements;
    
public:
    void push(const T& element) {
        elements.push_back(element);
    }
    
    void pop() {
        if (!elements.empty()) {
            elements.pop_back();
        }
    }
    
    T top() const {
        if (!elements.empty()) {
            return elements.back();
        }
        throw out_of_range("栈为空!");
    }
    
    bool empty() const {
        return elements.empty();
    }
    
    int size() const {
        return elements.size();
    }
};

int main() {
    // 使用int类型的栈
    Stack<int> intStack;
    intStack.push(10);
    intStack.push(20);
    intStack.push(30);
    
    cout << "栈顶元素: " << intStack.top() << endl;
    intStack.pop();
    cout << "弹出后栈顶元素: " << intStack.top() << endl;
    
    // 使用string类型的栈
    Stack<string> stringStack;
    stringStack.push("Hello");
    stringStack.push("World");
    
    cout << "字符串栈顶: " << stringStack.top() << endl;
    
    return 0;
}

类模板与函数模板的区别

特性 函数模板 类模板
定义方式 template <typename T> 函数定义 template <typename T> class 类名
实例化 自动根据参数类型推导 需要显式指定类型参数
使用场景 通用算法 通用数据结构
成员函数 不适用 可以在类内或类外定义

模板特化

模板特化允许我们为特定的类型提供特殊的实现。

模板特化的类型

  • 全特化：为所有模板参数提供具体类型
  • 偏特化：为部分模板参数提供具体类型

函数模板特化示例

#include <iostream>
#include <cstring>
using namespace std;

// 通用模板
template <typename T>
bool isEqual(T a, T b) {
    return a == b;
}

// 为const char*类型特化
template <>
bool isEqual<const char*>(const char* a, const char* b) {
    return strcmp(a, b) == 0;
}

int main() {
    int x = 5, y = 5;
    cout << "整数比较: " << isEqual(x, y) << endl;
    
    const char* str1 = "hello";
    const char* str2 = "hello";
    cout << "字符串比较: " << isEqual(str1, str2) << endl;
    
    return 0;
}

类模板特化示例

#include <iostream>
using namespace std;

// 通用类模板
template <typename T>
class Container {
private:
    T value;
public:
    Container(T v) : value(v) {}
    void print() {
        cout << "通用容器: " << value << endl;
    }
};

// 为bool类型特化
template <>
class Container<bool> {
private:
    bool value;
public:
    Container(bool v) : value(v) {}
    void print() {
        cout << "布尔容器: " << (value ? "真" : "假") << endl;
    }
};

// 为指针类型偏特化
template <typename T>
class Container<T*> {
private:
    T* value;
public:
    Container(T* v) : value(v) {}
    void print() {
        cout << "指针容器: " << *value << endl;
    }
};

int main() {
    Container<int> intContainer(42);
    intContainer.print();
    
    Container<bool> boolContainer(true);
    boolContainer.print();
    
    int num = 100;
    Container<int*> ptrContainer(&num);
    ptrContainer.print();
    
    return 0;
}

实际应用：模板特化在标准库中广泛应用，例如std::vector<bool>就是对bool类型的特化实现。

模板编程的最佳实践

模板使用建议

  1. 优先使用函数模板实现通用算法
  2. 使用类模板实现通用数据结构
  3. 合理使用模板特化处理特殊情况
  4. 注意模板代码的可读性和维护性
  5. 使用SFINAE(Substitution Failure Is Not An Error)技术进行条件编译

常见模板编程技巧

#include <iostream>
#include <type_traits>
using namespace std;

// 使用SFINAE进行条件编译
template<typename T>
typename enable_if<is_arithmetic<T>::value, T>::type
add(T a, T b) {
    return a + b;
}

// 对于非算术类型，这个函数不会被实例化
template<typename T>
typename enable_if<!is_arithmetic<T>::value, T>::type
add(T a, T b) {
    cout << "非算术类型，无法相加" << endl;
    return T();
}

int main() {
    cout << "整数相加: " << add(5, 10) << endl;
    cout << "浮点数相加: " << add(3.14, 2.71) << endl;
    
    // 下面的代码会导致编译错误，因为string不是算术类型
    // string s1 = "Hello", s2 = "World";
    // cout << add(s1, s2) << endl;
    
    return 0;
}

总结

模板是C++中非常强大的特性，它使得我们能够编写类型安全、高效且可重用的代码。通过函数模板、类模板和模板特化的组合使用，我们可以构建出灵活而强大的软件系统。

学习建议：掌握模板编程需要实践和经验积累。建议从简单的函数模板开始，逐步学习类模板和模板特化，最终掌握高级模板技巧。
