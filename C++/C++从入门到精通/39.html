代码格式规范

// 良好的代码格式示例
#include <iostream>
#include <vector>
#include <string>

class StudentManager {
private:
    std::vector<std::string> studentNames;
    int studentCount;

public:
    // 构造函数
    StudentManager() : studentCount(0) {
        studentNames.reserve(100);  // 预分配空间
    }

    // 添加学生
    void AddStudent(const std::string& name) {
        if (name.empty()) {
            std::cerr << "错误：学生姓名不能为空" << std::endl;
            return;
        }
        
        studentNames.push_back(name);
        studentCount++;
        std::cout << "成功添加学生: " << name << std::endl;
    }

    // 显示所有学生
    void DisplayAllStudents() const {
        if (studentNames.empty()) {
            std::cout << "暂无学生信息" << std::endl;
            return;
        }

        std::cout << "学生列表:" << std::endl;
        for (size_t i = 0; i < studentNames.size(); ++i) {
            std::cout << (i + 1) << ". " << studentNames[i] << std::endl;
        }
    }
};
代码规范要点：
  • 使用有意义的变量名和函数名
  • 保持函数短小精悍，单一职责
  • 适当添加注释，解释复杂逻辑
  • 使用const修饰不会修改的参数和成员函数
  • 合理使用空格和缩进，提高可读性

软件架构设计

三层架构说明

  1. 表示层：负责用户界面和交互，接收用户输入并显示结果
  2. 业务逻辑层：处理核心业务逻辑，协调数据流动和业务规则
  3. 数据访问层：负责与数据源交互，提供统一的数据访问接口

调试技巧与工具

常用调试方法

调试方法 描述 适用场景
打印调试 使用cout或cerr输出变量值和执行路径 简单问题、快速验证
断点调试 在IDE中设置断点，逐步执行代码 复杂逻辑、运行时错误
内存检查 使用Valgrind等工具检测内存泄漏 内存管理问题
单元测试 为每个函数编写测试用例 确保函数正确性、回归测试

GDB调试示例

// 编译时加入调试信息
g++ -g -o myprogram main.cpp

// 启动GDB调试
gdb ./myprogram

// 常用GDB命令
(gdb) break main          // 在main函数设置断点
(gdb) run                 // 运行程序
(gdb) next                // 执行下一行
(gdb) step                // 进入函数
(gdb) print variable      // 打印变量值
(gdb) backtrace           // 查看调用栈
(gdb) watch variable      // 设置观察点
(gdb) continue            // 继续执行
(gdb) quit                // 退出GDB

调试最佳实践

  • 使用版本控制系统（如Git）管理代码变更
  • 编写可测试的代码，避免过度耦合
  • 使用断言(assert)检查程序假设
  • 记录详细的日志，便于问题追踪
  • 学会使用IDE的调试功能，提高调试效率

核心代码实现

// Student.h - 学生类定义
#ifndef STUDENT_H
#define STUDENT_H

#include <string>

class Student {
private:
    std::string name;
    int id;
    double mathScore;
    double englishScore;
    double computerScore;

public:
    Student(const std::string& studentName, int studentId);
    
    // Getter方法
    std::string GetName() const { return name; }
    int GetId() const { return id; }
    double GetMathScore() const { return mathScore; }
    double GetEnglishScore() const { return englishScore; }
    double GetComputerScore() const { return computerScore; }
    
    // Setter方法
    void SetMathScore(double score);
    void SetEnglishScore(double score);
    void SetComputerScore(double score);
    
    // 计算平均分
    double CalculateAverage() const;
    
    // 显示学生信息
    void DisplayInfo() const;
};

#endif // STUDENT_H
// GradeManager.h - 成绩管理类定义
#ifndef GRADE_MANAGER_H
#define GRADE_MANAGER_H

#include <vector>
#include <string>
#include "Student.h"

class GradeManager {
private:
    std::vector<Student> students;
    
public:
    // 添加学生
    void AddStudent(const Student& student);
    
    // 根据ID查找学生
    Student* FindStudentById(int id);
    
    // 显示所有学生信息
    void DisplayAllStudents() const;
    
    // 计算班级平均分
    double CalculateClassAverage() const;
    
    // 保存数据到文件
    bool SaveToFile(const std::string& filename) const;
    
    // 从文件加载数据
    bool LoadFromFile(const std::string& filename);
};

#endif // GRADE_MANAGER_H
